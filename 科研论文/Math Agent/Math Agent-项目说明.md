# Math Agent 项目说明

## 项目目标

建立一个本地运行的小学数学科研论文智能体集群：输入研究主题、论文类型、目标期刊和研究方向后，完成文献检索、全文解析、证据整理、大纲规划、分章节写作、审稿修订、模型图生成和 Word/PDF 初稿导出。

## 任务拆分

1. 总编辑 Agent 登记项目，收窄研究问题并检查目标期刊要求。
2. Literature Research Agent 检索 OpenAlex、Crossref、Semantic Scholar 和公开网页，合并重复文献并核对 DOI。
3. Evidence Agent 解析已获取的 HTML/PDF，从原文提取可定位片段，建立证据卡片和证据矩阵。
4. 总编辑 Agent 根据证据矩阵生成大纲，人工审核通过后分配章节。
5. Theory、Method、Result 等子 Agent 并行写作，每节绑定允许使用的证据 ID。
6. Reviewer Agent 审查论证、方法、结果、表达和结构；Citation Agent 审查引文、DOI 和参考文献表。
7. 总编辑 Agent 按问题位置派发定向修订，保留每个版本。
8. 生成标题、摘要、关键词、模型图和技术路线图。
9. 导出 Markdown、DOCX、PDF，并在本库更新索引。

## 写入规则

- 原始网页、PDF 和 API 返回物进入项目代码目录的 `data/raw/`；Obsidian 只保存链接、摘要和人工可读的整理结果。
- 一篇文献一张文献卡片，一个论断一行证据矩阵。
- 没有原文定位的内容不能标记为“可写入”。
- Result Agent 没有真实数据时只能生成研究设计、评价工具和待采集数据方案，不生成课堂成效。
- 草稿、审稿意见和修订稿按版本保存，保留可回溯链路。
- 终稿索引只登记完成引用核查和人工终审的文件。

## 与代码工作区的关系

Python 和 LangGraph 代码位于当前工作区的 `math_agent/`；本 Obsidian 目录是面向人的项目资料库。代码运行后，把文献卡片、证据矩阵、草稿和日志同步到本库。

## 当前重点阶段

当前先实现文献研究引擎：文献检索、全文获取、文档解析、逐篇研读、文献卡片、证据矩阵和引用核验。多 Agent 写作、审稿、修订、图件和导出按阶段逐步接入。

## 当前默认题目

共同目标下“十几减9”课内三层练习的梯度设计与文本评价——以一年级下册一个课时为例。当前 SQLite 文献库登记 48 条来源，正文采用 39 条参考文献；该题目仍是首轮验证题，后续可替换为新的研究主题。
