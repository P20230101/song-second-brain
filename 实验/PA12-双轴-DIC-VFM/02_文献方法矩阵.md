# PA12 双轴-DIC-VFM｜文献方法矩阵

本矩阵登记已通过题名/摘要筛选、并完成 MinerU 非 OCR 全文提取的 8 篇方法论文。它用于比较“数据输入—同步—识别—验证”链条，不把其他材料的参数直接移植到 PA12。页码、图号和 MatchID 2019 字段必须在逐图核验后补齐。

## 统一字段

| 字段 | 记录规则 |
|---|---|
| 研究问题 | 用一句话描述要识别或验证的对象 |
| 全场输入 | DIC 位移、应变、网格、ROI、缺失处理 |
| 边界输入 | 力、位移、牵引、约束及其时间基准 |
| 识别方法 | VFM/FEMU/应力重构、参数化本构和优化器 |
| 稳健性 | 噪声、虚场、边缘、网格、初值和稳定性约束 |
| 验证 | 独立加载路径、整体曲线、有限元或材料稳定性 |
| 可迁移动作 | 在本项目中能直接转为哪一个数据字段、脚本步骤或预试验 |
| 证据状态 | `全文已提取`、`页码待核验`、`全文缺失` 三选一 |

## PA12 项目待补字段

以下字段没有从其他材料论文直接继承，必须由 MatchID 2019 导出样例或预试验填写：

- MatchID 工程文件/图像序列的帧号、时间戳、坐标单位和 ROI；
- subset、step、应变窗口、滤波、相关质量和边缘缺失规则；
- 双轴力/位移通道名称、单位、采样时钟和触发事件；
- 每个 DIC 帧对应的力/位移插值方法及同步残差；
- PA12 的候选本构模型、应力比、加载速度和独立验证路径。
