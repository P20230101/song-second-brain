# 双轴-DIC-VFM｜帧—力—位移同步验证

## 目标

为每个用于 VFM 的 DIC 帧建立唯一、可追溯的力/位移时刻，并把同步残差作为试验质量字段。相机帧率和力采样率可以不同；必须验证时间映射，不能只比较两个标称频率。

## 输入接口

设备与触发的实际参数先填写 [[01_设备与同步核对表]]；共同触发和异常事件先写入 `同步/events.csv`。本页只处理已经能回溯到原始文件的帧—采样映射。

| 输入 | 最小字段 | 来源 |
|---|---|---|
| DIC | `frame_id`, `t_frame`, `u`, `v`, 应变场、质量/缺失标记 | MatchID 2019 导出 |
| 力通道 | `t_force`, `F_x`, `F_y`（按真实通道填写） | 试验机/DAQ |
| 位移通道 | `t_disp`, `d_x`, `d_y`（按真实通道填写） | 试验机/编码器 |
| 触发事件 | `trigger_id`, `t_trigger` | 相机/控制器/DAQ |

## 映射定义

对第 `i` 个 DIC 帧，记录：

```text
frame_id_i → t_frame_i → (t_force_i, F_x_i, F_y_i) → (t_disp_i, d_x_i, d_y_i)
```

若采样时刻不重合，必须在试验记录中写明采用的插值或最近邻规则，并保存映射后的表格。同步残差至少记录：

```text
r_force_i = t_force_i - t_frame_i
r_disp_i  = t_disp_i  - t_frame_i
```

## 验证步骤

1. 检查所有时间戳的单位、起点、单调性和触发编号。
2. 用触发事件或明显载荷变化估计固定延迟；固定延迟必须在试验前记录，不能试后凭拟合曲线任意平移。
3. 对每个 DIC 帧生成唯一的力/位移记录，统计同步残差的中位数、最大值和异常帧比例。
4. 用整体力—位移曲线检查映射后是否存在跳点、反向或通道错位。
5. 对同一帧分别使用原始、插值和剔除异常点版本，比较 VFM 残差和参数漂移。
6. 在正式试验前预先写下可接受同步阈值；阈值应由加载速度、采样精度和 VFM 敏感性共同确定，不在本模板中替设备拍脑袋设定。
