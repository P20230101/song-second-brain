# 双轴-DIC-VFM｜同步采集与预试验方案

本页固定双轴试验机、MatchID DIC 与 VFM 的测量闭环。它先保证数据可用，再讨论材料、本构模型和创新点；不是对设备功能、孙振平论文或本构识别结果的预先结论。

## 当前证据与边界

| 内容     | 已知信息                                              | 使用边界                           |
| ------ | ------------------------------------------------- | ------------------------------ |
| 设备     | 用户提供的海报写为“直流驱动磁悬浮动态双轴拉压试验系统”                      | 设备型号、各轴能力、控制器和夹具仍需说明书/校准资料核对   |
| 设备海报参数 | 瞬时速度 0–4 m/s；拉压载荷 0–10 kN；采样频率 1 kHz；位移行程 ±150 mm | 这是海报转录，不能自动推导为相机帧率、每轴能力或可用试验窗口 |
| 图像测量   | 用户确认当前路线用 MatchID 2019 做 2D DIC，先完成散斑、力传感器和拍照配对 | 相机、镜头、帧率、平面标定和触发接口待核对；3D 仅作为未来扩展 |
| VFM 输入 | 用户要求每帧图像与力/位移对应，作为本构拟合前提                          | 还需确定准静态或动态虚功形式、边界条件、材料与待识别参数   |

## 核心规则：一对一映射，不是强行同频

**DIC 相机帧率不需要等于试验机的 1 kHz 数据采样率。**真正必须满足的是：每张进入分析的图像帧，均能在同一时间基准上唯一对应到力、位移与控制状态。

对第 `i` 帧，必须保存：

```text
frame_id → camera_time → trial_time → DAQ_sample_or_interpolation → force/displacement/control state
```

若相机和 DAQ 不是同一硬件时钟，必须用已记录的触发事件确定时钟关系，例如 `t_DAQ = a × t_camera + b`，并保存事件残差。只有在映射经验证后，才允许从连续的 DAQ 序列取该时刻的力/位移；插值方法和版本必须随数据保存。不能只凭两条曲线形状相似、文件名顺序相同或“标称频率相同”完成配对。

高速 DIC 的良好实践将相机同步方法和同步误差列为应报告的测量参数；外部 TTL 触发是已有多相机试验的实际做法。[高速 DIC 的报告要求综述](https://doi.org/10.1111/str.70018)；[外部 TTL 触发的 DIC 试验示例](https://doi.org/10.1016/j.ijsolstr.2021.111223)

## 推荐的同步架构

按可靠性从高到低采用下列方案；现场可用接口决定最终选择。

1. **共同硬件触发与事件记录（首选）**：同一触发器/DAQ 数字输出启动相机和试验控制记录；DAQ 保存每个触发沿的样本编号/时间，相机保存帧号/硬件时间戳。
2. **同时 TTL 触发加双端时间戳**：两端接收同一触发信号，在开始、结束以及可行时的中间都记录事件；据此估计偏移和时钟漂移。
3. **事后事件对齐（仅作受限备选）**：只有在硬件触发无法取得时，使用独立、可识别的事件进行对齐并留出另一事件验证。不得仅用力—位移曲线的峰值对齐。

在未确认控制器和 MatchID/相机接口前，不设定虚假的毫秒阈值。同步验收阈值应由相机曝光/帧间隔、试验速率、视场比例、允许的图像位移和 VFM 对误差的敏感性共同确定，并在预试验后写入记录。

## 预试验的固定顺序

### A. 无试样的时间基准验证

1. 记录控制器、DAQ、相机、触发器的型号、时钟来源、采样/帧率、触发极性和导出格式。
2. 用相同触发链采集开始、结束和可行时的中间事件；不装试样、不进行正式加载。
3. 生成 `帧-采样映射.csv`，检查每帧是否唯一、时间是否单调、是否存在缺帧或未匹配触发事件，并计算偏移/漂移残差。
4. 若映射不唯一或残差超过预设测量容许范围，先修正触发、时间戳或导出设置；不进入散斑和本构拟合。

### B. DIC 测量链验证

1. 在代表性试样表面制备散斑，记录喷涂材料、图案、照明、镜头、光圈、曝光、视场和像素尺度。
2. 完成 2D DIC 平面标定、刚体检验和面外运动风险评估；不得把旧工程参数直接移植到正式数据。若风险不可接受，再评估是否需要立体测量。[面外运动对 2D/3D DIC 的影响研究](https://doi.org/10.1016/j.optlaseng.2008.05.005)
3. 用低速、小载荷、可安全停止的加载运行，核对 DIC 位移趋势与机器位移、图像质量和相关残差；这不是材料参数识别试验。
4. 固定并保存 MatchID 软件版本、标定文件、子区/步长、滤波、应变计算和导出设置。未经同一配置复核的结果不能与正式数据混合。

### C. 试样与 VFM 可行性验证

1. 先选择一个低复杂度、可视场覆盖、夹具适配的基准加载路径；其材料、几何和加载率须由后续文献与设备资料决定。
2. 为每个候选图像帧组装同步状态：DIC 位移/应变场、边界条件、力、位移、时间、坐标变换与同步残差。
3. 用一部分独立试样/加载路径做参数识别，保留另一部分做验证；图像帧不是独立试样重复。
4. 只有同步记录、DIC 质量和边界条件完整时，才比较 VFM 预测与保留数据的整体力—位移及全场响应。

## 准静态与动态 VFM 的分流门槛

设备可达 4 m/s 不表示第一组论文必须做动态 VFM。若惯性可忽略并经平衡/速率效应检查，使用准静态虚功平衡；若试验进入不可忽略的惯性或高应变率工况，则需要动态 VFM，且必须将加速度/惯性项和高时间分辨率场量纳入识别。两种形式不能混用。

已有动态 VFM 研究明确把全场应变和加速度数据用于惯性项，并报告不同时间步下的识别稳定性问题。[动态 VFM 与异质冲击试验研究](https://doi.org/10.1016/j.matdes.2021.109594) 因而推荐的推进顺序是：**先完成同步可靠的准静态双轴预试验闭环，再由文献、材料速率敏感性和可用高速成像能力决定是否把动态 VFM 作为大论文扩展。**

## 固定的数据包与命名

每次试验应以试样为单位建立目录；原始数据不覆盖，处理结果另存。

```text
实验/<项目名>/<试样编号>/
  raw/
    images/                         # 相机原始图像
    daq/                            # 力、位移、触发原始导出
    calibration/                    # 原始标定文件副本
  metadata/
    trial.md                        # 试样、材料批次、夹具、加载与异常事件
    帧-采样映射.csv
  dic/
    settings.md                     # MatchID 设置与版本
    fields/                         # 导出的场量
  vfm/
    input_manifest.md               # 被纳入识别的帧和处理版本
    identification.md
    validation.md
```

`帧-采样映射.csv` 的最低字段如下；实际力/位移通道名以设备导出为准，不预设轴数或传感器数。

| 字段 | 含义 |
|---|---|
| `specimen_id` | 唯一试样编号 |
| `frame_id`、`image_file` | 相机帧和原始图像文件 |
| `camera_time_s` | 相机硬件时间戳或已说明来源的时间 |
| `trial_time_s` | 转换到试验统一时间轴后的时刻 |
| `trigger_event_id` | 用于建立/验证映射的触发事件 |
| `daq_sample_index` | 对应的 DAQ 样本；若插值，记录相邻样本范围 |
| `force_*`、`displacement_*` | 该时刻的实际导出通道值与单位 |
| `alignment_residual_ms` | 此帧映射的同步残差 |
| `sync_status` | 已验证、待复核或不纳入 VFM |
| `processing_revision` | DIC、映射和 VFM 处理版本 |

## 当前不能跳过的确认项

1. 设备说明书和控制器导出示例：确认 10 kN、±150 mm、1 kHz 的定义及每个加载通道能力。
2. 相机与 MatchID 配置：确认 2D/3D、相机数、分辨率、最高可用帧率、曝光、镜头和触发接口。
3. 同步接口：控制器/DAQ 是否能输出或记录 TTL 触发，能否获得每帧硬件时间戳。
4. 第一种材料、可加工试样几何、夹具和预期的本构模型。
5. 第一篇小论文到底验证准静态流程，还是研究动态惯性条件；在上述四项完成前不决定。

## 成功标准

进入正式双轴 VFM 试验前，必须同时满足：

- 每个纳入分析的图像帧有唯一、可复核的力/位移时间映射；
- 同步误差、DIC 标定/处理设置和坐标变换均已记录；
- 试样、加载、原始图像和 DAQ 数据可追溯；
- VFM 公式与准静态/动态工况一致；
- 识别与验证使用独立试样或独立加载路径。
