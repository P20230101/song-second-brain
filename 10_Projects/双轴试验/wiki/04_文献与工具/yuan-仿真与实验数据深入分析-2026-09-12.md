# yuan 文件夹｜仿真与实验数据深入分析

> 本页把 `yuan` 文件夹的真实文件证据、当前 2D DIC 路线和可发表的研究问题分开记录。`yuan` 的历史文件不能被自动升级为你的当前设备事实；相机、平面标定、触发接口、力的单位和试样厚度仍以你提供的现场记录为准。3D 只在取得双视角与空间标定资料后作为扩展。

## 1. 先给结论

1. **当前测量路线按 2D DIC 执行。**这是用户确认的项目事实。它需要平面标定、面内位移/应变、刚体检验和面外运动风险评估；不把尚未取得的双视角资料写成当前条件。
2. **`yuan` 里的 MatchID 工程是二维样例。**13 个 `Job.m2inp` 文件的头部为 `MatchID Input file 2019.2.2`，4 个 `.mti` 文件的头部明确写着 `MatchID 2D-Version 19.2.2.0`。它们可用于复现 MatchID 2019 的 ROI、子区、步长、导出和文件命名，并作为当前 2D 处理链的基线。
3. **文件夹包含真实实验序列，也包含待解释的仿真/处理文件，但还没有一条完整、可审计的“图像帧—四通道力—位移—2D DIC 场—VFM 参数”链。**目前最重要的工作不是再堆材料参数，而是补齐数据血缘和同步接口。
4. **建议的小论文问题已经收窄：**在同一 PA12 十字形试样和同一双轴加载设备上，比较“整体力—位移”与“同步 2D DIC 全场 + 边界力”的本构识别可辨识性、重复性和独立加载路径预测误差；把平面标定、ROI 边缘缺失、面外运动风险和时间偏移作为可控误差因素。
5. **大论文再扩展：**在小论文的验证链通过后，增加应力比、加载速率、拉伸/压缩方向和各向异性/黏弹塑性模型，形成“试验—2D DIC—VFM/FEMU—有限元预测”的连续主线；3D 仅在具备双视角与空间标定后作为独立扩展。

### 2.1 已看到的实验序列

XY 目录有 10 个主要序列，文件夹名包含 `X-05-0.1-01`、`X-06-1.0-01`、`X-07-10-01`、`Xy-0.1-01`、`XY-0.1-02`、`Xy-03-10-01`、`Xy-04-1-01`、`Y-09-0.1-02`、`Y-10-1-01`、`Y-11-10-01`；每个序列都有图像和同名 `.jpg.dat`，帧数约 21–1,825。XZ 目录有 4 个主要序列，帧数约 81–546。

这些名称适合暂作数据集 ID，但 `0.1/1/10` 的物理含义（速度、应力比或其他工况）不能仅从文件名推断。正式分析前应在 `metadata/trial.md` 逐项确认：工况、单位、轴向、起止事件、试样编号和是否为同一批次。

### 2.2 旧 MatchID 2019 工程能告诉我们的内容

旧 `Job.m2inp` 中可以直接读到以下事实：

- 使用 MatchID 输入文件格式 2019.2.2；每个工程列出参考图和逐帧变形图。
- 历史工程的全局子区/应变窗口可见 `15` 像素，步长/插值等设置需按每个文件分别读取，不能假设所有工程相同。
- 一些工程使用多边形 ROI 和引伸计点；输出分隔符为分号。
- 代表性导出 `Img000000.jpg.csv` 的表头重复 `x_pic,y_pic,u,v,r,sigma,correlationPath,ShapeIndex`，没有 `Z/W` 或立体相机编号；这进一步证明该导出是二维场量历史样例，而不是正式 3D DIC 导出。
- 示例工程把输出单位设为像素，并给出 `0.035353` 等像素换算值；这个值是旧工程设置，不是你的当前标定值。
- 工程路径引用旧电脑目录，迁移到当前 `D:\C盘迁移\Desktop\yuan` 后只能复制为“可复现副本”并记录路径变更，不能静默改写原文件。

旧 `.mti` 明确为 2D 版本。因此它可以作为当前 2D 处理基线；正式处理应保存平面标定、参考帧、ROI、相关参数和坐标系定义。若未来引入 3D，必须另建工程并保存空间标定、相机内外参数与标定残差。

## 3. 数据血缘与当前缺口

```text
原始图像序列
        │ 共同硬件触发 + 相机时间戳
        ▼
MatchID 2019 2D 工程（平面标定、ROI、subset/step、相关质量）
        │ 每帧导出 X,Y,Z,U,V,W、应变、质量、frame_id
        ├───────────────┐
        ▼               ▼
试验机四通道力/位移   events.csv（触发、帧号、机器采样号、时间戳）
        └──────┬────────┘
               ▼
同一时间轴的边界牵引 + 2D DIC 全场
               ▼
VFM（模型参数识别） ↔ FEMU/有限元（独立交叉验证）
               ▼
冻结参数后的独立试样/独立加载路径预测
```

当前已发现的可追溯性问题：

1. `Z-0.1-06_C001H001S0001` 目录出现 227 张 JPEG 与 228 个伴随数据文件；`XZ-10-04_C001H001S0001` 有图像但未见对应 `.cihx`。这两类不一致必须记录为数据质量事件，不能自动补帧。
2. `CIHX` 元数据中的旧 XZ 序列包含 1024×1024 JPEG、60 或 500 fps、`skipFrame=10`、`syncOutTimes=1` 等字段；它们是旧采集证据，不是当前 2D DIC 参数，也不能单凭字段名推断触发延迟为零。
3. XY 图像目录没有与之配套的平面标定记录和硬件触发日志。现有 2D `.mti` 与 `.m2inp` 可作为处理基线，但不能替代当前试验的参数记录。
4. CSV 表头 `Serie;X;Y` 还不足以区分坐标、位移、应变或引伸计曲线。所有字段必须在数据字典中加上物理量、单位、坐标系、来源文件和帧/时间索引。
5. `.vfm` 是二进制结果文件，未获得格式说明或可读导出前，不把它解释成“已识别的本构参数”。需要从 MatchID/VFM 软件导出文本结果、模型名、虚场、ROI、输入帧范围和残差。

## 4. 当前 2D DIC—VFM 实现路线

### 4.1 2D DIC 测量层

1. 在正式相机位置下完成平面标定；保存标定板规格、像素尺度、观测平面、坐标系和标定误差。
2. 用固定刚体目标做静态重复和小幅已知面内平移；检查 `(U,V)` 的均值、标准差、面内系统趋势和边缘区域误差。
3. 对 PA12 试样制作可重复散斑，先以低风险加载确认相关质量、遮挡、中心区有效 ROI 与面外运动风险。
4. 在 MatchID 2019 2D 工程中固定坐标系、参考帧、ROI、subset、step、应变窗口、滤波和质量阈值。每次改变建立新处理版本。
5. 导出至少包含 `frame_id, point_id, X,Y,U,V, strain_components, correlation_quality, valid_mask` 的长表；若 MatchID 2019 无法一次导出全部字段，保留原生导出并写转换映射，不覆盖原文件。

### 4.2 同步与边界层

- 采用共同硬件触发或同一可观测事件作为时间零点；相机帧率与 1 kHz 采样率不需要相等，但每张进入 VFM 的图像必须映射到唯一的机器时间/插值区间。
- 四个力通道分别保存原始值、单位、符号、零点和校准信息；不能把四通道合成为一个总力后再假设边界牵引均匀。
- `events.csv` 至少记录 `trial_id,event_id,trigger_id,frame_id,machine_sample_id,camera_time,machine_time,offset,drift,operator_note`。
- 同步误差、丢帧、重复帧、触发延迟和漂移作为数据字段进入 VFM 敏感性分析；不要只在实验记录中口头说明“频率一致”。

### 4.3 VFM 与有限元交叉层

VFM 不是“把曲线调到重合”的黑箱。每个候选模型至少要说明：

- 运动学：使用 2D DIC 的面内位移后，按平面应力或平面应变假设建模；厚度、面外运动风险和可用表面必须实测或明确说明。
- 边界：四通道力如何转换成各边界的牵引或合力约束；夹具/狭缝端部是否剔除。
- 本构：先做 L0 线弹性各向同性/正交各向异性基线，再依据 PA12 的速率、加载历史和卸载/保持证据选择弹塑性、超弹性或黏弹塑性；不从“VFM 很高级”直接跳到高阶模型。
- 目标函数：内部虚功、外部虚功、虚场选择、ROI 掩膜、帧权重、单位和正则化；训练帧与验证帧必须分开。
- 交叉验证：同一数据分别做整体力—位移、2D DIC 全场 VFM、FEMU/有限元更新和联合目标，报告参数、场量残差、独立路径预测误差和计算成本。

仿真阶段先使用合成场量验证“能否识别”，再把真实 2D DIC 噪声、边缘缺失、面外运动风险和时间偏移注入合成数据，得到识别稳定性边界。有限元输入文件应与 `yuan` 的 MatchID 文件分开命名；目前没有证据证明 `.m2inp` 是有限元求解器输入。

## 5. 由文献交叉验证得到的候选创新点

| 优先级 | 可检验问题 | 为什么可行 | 需要的证据 |
|---|---|---|---|
| 主线（小论文） | 同一 PA12 双轴试验中，整体力—位移与同步 2D DIC 全场对本构参数的可辨识性、重复性和独立路径预测有何差异？ | 设备已有双轴能力；VFM 需要全场运动和边界力；可用同一试样分训练/验证帧，避免增加复杂材料变量 | 2D DIC 场、四通道力/位移、至少一条保留验证路径、VFM 与 FEMU/曲线基线对照 |
| 质量扩展 | 平面标定误差、面外运动风险、ROI 边缘缺失和同步偏移会把参数误差放大到什么程度？ | 文献反复指出面外运动、边缘缺失和噪声会影响 VFM；当前数据可先做 2D 基线 | 标定误差、刚体测试、边缘掩膜、时间扰动试验、参数敏感性曲线 |
| 大论文扩展 | 应力比、速率、拉伸/压缩方向和材料各向异性如何改变可辨识性与失效局部化？ | Sun 论文提供多边界加载案例，PA12 论文提供 XY/XZ 与速率基线；但必须在你的设备和材料上重做 | 多路径试验、独立批次、有限元模型和冻结参数预测 |

支撑这些设计的公开方法来源包括：VFM 专著对原理、非线性 VFM 和实验设计的系统说明（[Pierron & Grédiac, 2012](https://link.springer.com/book/10.1007/978-1-4614-1824-5)）；3D DIC 在热塑性大变形中的双相机立体测量案例（[Grytten et al., 2009](https://doi.org/10.1016/j.polymertesting.2009.05.009)）；VFM 与立体 DIC 对面外运动和各向异性参数识别的实验验证（[Zhang et al., 2018](https://www.sciencedirect.com/science/article/pii/S0143816617310163)）；关于参数必须被试验场“激活”且要做构型/加载设计的可辨识性分析（[Grama et al., 2015](https://doi.org/10.1016/j.actamat.2014.11.052)）；以及 PA12 成形方向、速率和本构标定需要联合验证的研究（[Schneider & Kumar, 2020](https://www.sciencedirect.com/science/article/pii/S0142941819320860)）。国际 DIC Society 的实践材料也明确区分了 2D 的长度标定和 3D 的相机空间标定（[DIC Good Practices](https://digitalimagecorrelation.org/)）。

## 6. 问题区间与论文分层

### 6.1 小论文：先解决一个窄问题

**建议题目（工作题目）：**

> *Synchronized stereo-DIC and virtual-fields identification of PA12 under biaxial loading: comparison with global force–displacement calibration and sensitivity to data quality.*

中文可写作：**《同步 2D DIC—VFM 的 PA12 双轴本构识别：与整体力—位移标定的交叉比较及数据质量敏感性》**。

固定范围：

- 材料只选一种 PA12、一个已确认成形批次和一种十字形试样；先不把材料制备变量写成创新点。
- 加载先选两个归一化应力比（等双轴 $r=1$ 与一个非等双轴 $r\ne1$）；实际 $r=F_y/F_x$ 水平由设备安全窗口和预试验确定，不从文件夹名猜绝对力或速度。
- 每个路径先做预试验，再按独立试样重复；图像帧不是独立样本。
- 识别只从 L0 基线开始；只有当 2D 场量、同步、边界和模型误差通过，才升级一个更复杂的 PA12 模型。
- 结果必须同时给出：整体曲线误差、2D 场量残差、参数区间/重复性、保留路径预测误差、标定/面外风险/边缘/时间扰动敏感性。

### 6.2 大论文：沿同一证据链扩展

1. 扩展多个 $r=F_y/F_x$ 和加载速率，观察参数可辨识性而非只比较峰值。
2. 加入拉伸与压缩方向、卸载/保持段，判断是否需要速率相关或黏弹塑性模型。
3. 用有限元正问题复现实验边界；用 FEMU 与 VFM 交叉识别，报告两者的误差和计算成本。
4. 在未来具备双视角与空间标定条件后，再把 3D DIC 的面外位移/局部化与 PA12 各向异性、断裂位置和失效模式关联起来。
5. 最终形成“测量质量—本构识别—独立预测—工程应用”的连续章节，而不是堆积互不相连的试验。

## 8. 下一次只需提供一个最小匹配试验包

不需要先上传整个 `yuan` 文件夹。优先提供同一试验的以下 5 项：

1. 同一 2D DIC 图像序列中的 20–50 帧；
2. MatchID 2019 2D 工程文件或导出表（包含坐标、面内位移、应变、质量字段）；
3. 同期四通道力与位移导出表；
4. `events.csv` 或能指出 ARM/START/STOP/触发帧的事件记录；
5. 试样厚度、中心区尺寸、加载方向和一张带编号的试样/夹具图。
