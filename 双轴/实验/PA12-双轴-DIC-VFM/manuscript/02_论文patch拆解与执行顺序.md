# PA12 双轴 DIC–VFM 论文 patch 拆解与执行顺序

## 目的与成功标准

本文不是把计划包装成结果，而是把一个可投稿研究拆成可验收的最小 patch。每个 patch 必须同时回答四件事：

1. 它要证明哪一个主张；
2. 它需要哪一份原始证据；
3. 它最终生成哪张图、哪张表或哪段正文；
4. 什么结果会使该主张被降级、改写或删除。

整篇论文只有在以下条件同时满足时才达到“可投稿工作稿”标准：原始数据和设备记录可追溯；所有结果来自实际试样级数据；至少一个未参与拟合的路径或独立试样完成验证；图表、统计量、单位、参考文献和作者声明齐全；作者逐条核对正文、原文献和投稿系统要求。

## Patch 总览

| Patch | 科学问题 | 必需输入 | 主要产出 | 验收门 | 未通过时的处理 |
|---|---|---|---|---|---|
| P0 证据封存 | 项目中哪些是真实记录，哪些只是学习资料？ | 原始图像、机器 CSV、MatchID 工程、设备资料、打印记录、校准记录 | `source_manifest`、数据包目录、材料/设备身份表 | 每个结果字段都有来源文件和试样编号 | 删除无来源数字；保留为“待补” |
| P1 设备与同步 | 图像帧是否能映射到四通道力/位移？ | 触发记录、相机/控制器时间戳、采样频率、掉帧记录 | 映射模型、残差图、同步表 | 残差在预先规定阈值内，或其影响进入敏感性分析 | 改用分段/非线性映射，不能继续使用未经验证的线性映射 |
| P2 试样与中心区 | 十字形试样是否在中心 ROI 内产生有效响应？ | CAD、实测尺寸、厚度、夹具、FE 网格/边界、DIC 场量 | 图 2、图 3、几何表、中心区均匀性指标 | 中心区、臂根、圆角和狭缝端部的场量及失效位置可比较 | 缩小主张为“候选几何评估”，不能写成试样已验证 |
| P3 DIC 计量 | DIC 场量是否足以进入 VFM？ | 相机/镜头、标定、散斑、静止图、刚体图、MatchID 参数 | DIC 参数表、噪声底、无效点和边缘缺失统计 | 平面假设、相关质量、单位和掩膜得到记录 | 剔除不合格帧/批次，或改为 3D-DIC；不得静默修补 |
| P4 L0 VFM | 数据接口、单位、虚场和积分是否闭合？ | 位移/应变场、四通道边界力、厚度、边界区域、虚场定义 | 虚功残差、参数估计、条件性/灵敏度表 | 线弹性基线通过单位、符号、边界项和残差审计 | 停在 L0，先修正接口；不直接上复杂模型 |
| P5 模型升级 | 数据是否支持塑性、黏弹或各向异性？ | 分阶段加载历史、卸载/速率/取向证据、L0 残差 | 预先声明的升级模型、参数和适用区间 | 复杂模型相对 L0 有可量化改善且不靠同一数据过拟合 | 保留 L0 或删除无法支持的模型分支 |
| P6 扰动与不确定度 | 同步、ROI、subset、step 和应变窗口是否改变结论？ | P1/P3 基线、预先规定的参数扰动 | 敏感性图、参数区间、场残差、不确定度分解 | 测量链不稳定性与试样间离散性分开报告 | 降级结论，不将单一参数称为材料常数 |
| P7 独立验证 | 识别结果能否预测未参与拟合的数据？ | 独立路径或独立试样、冻结参数 | 验证曲线、空间残差、误差区间 | 参数在验证集冻结，不重新调参 | 只能报告拟合，删除“预测/验证”措辞 |
| P8 期刊封装 | 选定期刊的题名、摘要、图表、声明是否合规？ | 目标期刊最新版指南、作者资料、基金/保密状态 | 干净稿、投稿信、图件包、数据声明 | 仅选择一个期刊投稿；所有待补项清零 | 退回 P0–P7，不能靠语言润色弥补证据缺口 |

## 按论文结构的最小实现

### 1. 引言 patch

引言只保留四条证据链：SLS PA12 的批次/取向/厚度依赖；十字形试样中心区有效性；2D-DIC 的计量边界；VFM 的全场反演与验证要求。每个外部文献主张以 E001–E018 作为工作证据 ID，投稿前转换为数字引文。不得把本地学位论文中的候选尺寸、设备参数或实验趋势直接移入本文结果。

### 2. 方法 patch

方法章节必须能让另一位研究者按字段重建分析：

- 试样：材料牌号/批次、成形路线、打印方向、几何版本、厚度与公差；
- 设备：四通道量程、校准日期、夹具、控制模式、机器采样率；
- 图像：相机/镜头、图像尺寸、视场、像素尺度、帧率、曝光、照明、散斑；
- DIC：MatchID 版本、标定、subset、step、形函数、匹配准则、应变窗口、滤波和无效点规则；
- 同步：触发事件、帧号、机器时间、映射模型、残差、掉帧；
- VFM：坐标、单位、厚度、边界牵引换算、虚场、积分、拟合帧和验证帧；
- 统计：独立试样为统计单元，时间帧不作为独立重复。

### 3. 结果 patch

结果按“设备与同步 → 中心区 → DIC 质量 → 整体响应 → L0 VFM → 扰动 → 独立验证”顺序生成。先生成中间表和审计日志，再写正文。任何只存在于图像、手工截图或口头描述而没有机器可读来源的数值，不进入正式表格。

### 4. 讨论 patch

讨论必须区分：试样几何造成的载荷传递、DIC/同步造成的测量不确定度、PA12 批次与成形造成的材料离散性。只有在独立路径或独立试样上仍成立时，才可使用“识别能力提高”“预测有效”等强措辞；否则写为“在拟合集上拟合改善”。

## 12 小时工作节奏

这是执行顺序，不是对缺失数据的承诺。若 P0 发现原始数据不存在，剩余时间应转向收敛论文框架、证据注册表和数据请求清单，不应制造结果。

| 时间段 | 目标 | 交付物 |
|---|---|---|
| 0–1 h | 封存和核对输入 | P0 数据包清单、缺失项、材料/设备身份状态 |
| 1–3 h | 完成设备、同步和 DIC 接口 | P1/P3 表格、时间映射和 DIC 参数记录 |
| 3–5 h | 几何/FE/中心区审计 | P2 图表与中心区结论 |
| 5–7 h | L0 VFM 闭环 | P4 残差、参数、单位和边界审计 |
| 7–9 h | 扰动、统计和独立验证 | P6/P7 图表及不确定度 |
| 9–10 h | 中英文正文收敛 | 干净稿、图注、参考文献 |
| 10–11 h | 期刊适配 | 选定期刊版本、投稿信、格式清单 |
| 11–12 h | 作者审阅 | P8 签字式核对、数据声明、最终投稿包 |
