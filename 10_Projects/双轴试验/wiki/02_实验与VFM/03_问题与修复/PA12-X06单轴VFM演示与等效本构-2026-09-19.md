# 目标

选取一个真实数据链完整、曲线稳定、能够用于讲解的工况，建立从真实照片、DIC 场、Force 边界到 VFM 与等效本构拟合的最小闭环。当前演示工况为 `XY_X-06-1.0-01`，不是合成数据。

X-06 的优点是加载支路连续、力值和 DIC 帧能够一一对应，并且内外虚功趋势一致。它的限制是应变范围仍小，尚未覆盖清晰的塑性平台，因此适合做“方法闭环演示”，不适合直接宣布为最终 PA12 材料卡。

## 同一工况的证据链

1. 真实照片：第 58 帧。
2. 同一帧 DIC：从 `formal_vfm_input.csv.gz` 读取 `exx`，在真实坐标上绘制。
3. 外虚功：同步 Force 边界的力增量。
4. 内虚功：真实 DIC 场积分得到的 VFM 内部量。
5. 应力–应变：将两类虚功分别除以真实截面积 `A = 厚度 × 横向 DIC 跨度 = 52.36014 mm²`。

## VFM 不只有一张内外虚功图

VFM 检查至少分成三层：

- **趋势闭合**：`Wint` 与 `Wext` 是否随加载帧同步增长。
- **逐帧残差**：`Wint - Wext` 是否有系统性偏置、漂移或局部突变。
- **应力–应变闭环**：把内、外虚功分别变为等效应力，再与本构曲线拟合。

![VFM内外虚功与等效应力应变](../../../实验/PA12-双轴-DIC-VFM/reports/demo_XY_X-06-1.0-01/vfm_virtual_work_and_stress_strain.png)

![VFM闭合残差诊断](../../../实验/PA12-双轴-DIC-VFM/reports/demo_XY_X-06-1.0-01/vfm_closure_diagnostics.png)

当前残差不是零：相对 L2 为 4.737%，最大逐帧残差为 79.709 N。图中早期相对残差很大，是因为外虚功接近零时使用了小量归一化；因此报告同时保留绝对残差、RMSE 和相对 L2，不能只看百分比。

## 四类等效本构拟合

拟合目标是 X-06 的真实外虚功等效应力–应变曲线，优化器为 `scipy.optimize.least_squares`。内部等效应力只用于闭合对照，不参与把 VFM 残差“掩盖”掉。

![四类等效本构拟合](../../../实验/PA12-双轴-DIC-VFM/reports/demo_XY_X-06-1.0-01/vfm_equivalent_constitutive_four_models.png)

| 模型 | 参数 | RMSE / MPa | 说明 |
|---|---|---:|---|
| 线弹性 | `E=6089.33 MPa` | 0.634 | 可以描述总体斜率 |
| J2 理想弹塑性 | `E=6246.67 MPa, σy=19.996 MPa` | 0.501 | 会把末端弯折近似成屈服平台 |
| J2 线性硬化 | `E=6275.72 MPa, σy=17.375 MPa, H=10599.83 MPa` | **0.442** | 当前收敛成功模型中的最佳拟合 |
| J2 幂硬化 | `E=6280.87 MPa, σy=16.990 MPa, H=6589.92 MPa, n=0.927` | 0.442 | 迭代达到上限，暂不作为最终选择 |

当前等效模型选择规则是：只在 `least_squares success=True` 的模型中按应力 RMSE 选择。因此当前演示输出的等效参数为：

```text
E       = 6275.72 MPa
sigma_y = 17.38 MPa
H       = 10599.83 MPa
n       = 1.0（线性硬化特例）
nu      = 未由轴向VFM曲线识别
```

这组参数是 **X-06 当前有效应变范围内的等效参数**，不是 PA12 的最终通用参数。`nu` 需要横向 DIC 和双轴实验共同约束；当前 Phase 12 的 `nu` 接近 0，说明现有数据/目标函数对泊松比的约束不可信，不能直接写入最终材料卡。

## 左上角参数是什么意思

GUI 左上角的 `E/C10、sigma_y、H、n、nu` 等参数不是“校正按钮”，而是材料模型的控制量：

- `E` 或 `C10`：决定初始斜率；数值越大，初始曲线越陡。
- `sigma_y`：决定何时从弹性段进入塑性段。
- `H`：决定屈服后的硬化斜率。
- `n`：决定幂硬化曲率；它不是额外的力值。
- `nu`：决定横向变形与轴向变形的耦合；单轴轴向曲线本身不能可靠确定它。
- 超弹性模型中的 `D1`：控制体积可压缩性，不能和 J2 塑性参数混用。

因此调参数的实际含义是：改变本构模型，再比较模型曲线和真实 VFM 曲线的残差。只有在参数收敛、没有撞边界、并且由多种加载路径共同约束时，参数才有资格成为材料参数。当前 X-06 的塑性段太短，`sigma_y/H/n` 仍然弱可辨识。

## 复核后的重要更正

这组结果的**算术可以复现，但物理参数暂时只能作为诊断值**。方向审计发现真实 DIC 点云主轴约为 43.78°，而当前 Phase 8 求解器把实验名称中的 X 直接当成 DIC 全局 x 轴；仅把应变旋转到 DIC 点云主轴后，E 的诊断值就从 19096.75 MPa 变为约 12115.72 MPa。说明坐标方向假设会显著影响结果。

另外，当前等效应力图使用 `52.36014 mm² = 1.0 mm × 全局 y 跨度`，但点云主轴审计得到的横向跨度约为 9.17 mm；真实试样厚度和加载截面还需要从实验记录确认。故当前 `E、sigma_y、H、n` 不能进入最终 PA12 材料数据库，PPT中的参数页应解释为“当前假设下的等效拟合”，不能解释为材料真值。

图中第一加载点的 348.7% 相对残差来自小分母：`40.100 N / 11.500 N = 348.7%`；第 58 帧为 `63.657 N / 1099 N = 5.79%`。所以相对百分比不能单独判断 VFM 好坏，必须同时看绝对残差、RMSE 和相对 L2。

## 周期清理规则

只清理明确标记为 `legacy_*`、旧 QA 渲染目录、重复日志和已被当前结果替代的中间产物；保留原始 `.jpg/.dat`、Force.csv、formal_vfm_input、当前 VFM 结果、当前 X-06 演示包和脚本。无法判断是否淘汰的文件不自动删除，而是留在归档区并写入清理报告。

已更新自动化任务 `21-00`：每日 21:00 执行项目审查与旧生成物归档，生成清理清单，禁止删除真实原始数据。任务优先归档而非永久删除；不确定的文件保留。

## 当前结论

X-06 已经形成一个可讲解的真实数据计算链：照片 → DIC 场 → 内外虚功 → VFM 等效应力–应变 → 等效 J2 拟合。但它目前还不是物理上验收完成的材料闭环。下一步必须先确认 MatchID 世界坐标到试样加载坐标的变换、真实厚度和加载截面，再按试样坐标重算 VFM；在此之前不能把这组等效参数推广到所有 PA12 实验或写入最终材料数据库。
