# 02｜阶段计算

按顺序查看真实数据处理。每一阶段先确认上一阶段已经有结果，再继续下一阶段：

`Phase6 数据接入` → `Phase7 力值闭合` → `Phase8 单轴 VFM` → `Phase9 参数识别` → `Phase11 双轴 VFM` → `Phase12 联合识别`。

| 阶段 | 人话解释 | 产物 |
|---|---|---|
| Phase 6 | 读入真实 DIC 字段 | 帧、坐标、位移/应变场 |
| Phase 7 | 对齐照片和力 | 每帧力值、单位、同步状态 |
| Phase 8 | 先跑通单轴 VFM | 虚功平衡和残差 |
| Phase 9 | 识别材料参数 | 参数和误差 |
| Phase 11 | 接入双轴场量和边界力 | 双轴 VFM 结果 |
| Phase 12 | 联合单轴、双轴检查稳定性 | 最终参数和留出验证 |

如果 Phase 7 只有候选同步，只能做敏感性分析，不能写成实测同步精度。
