# 论文启发与 GitHub 工作时间线

## 使用方法

本页回答两个问题：

1. 你提供的论文和后续检索论文，具体启发了哪些可验证动作；
2. “松的第二大脑”在 GitHub 上是哪一天做了什么，产生了哪些文件。

日期以北京时间（Asia/Shanghai）为准；Git 提交短哈希是公开仓库中可追溯的版本锚点。论文的“启发”与“本项目结论”分开写，避免把别的材料、设备或软件参数直接移植到 PA12。

|---|---|---|---|

| Zhang et al., 2018, [VFM + special stereo-DIC](https://www.sciencedirect.com/science/article/pii/S0143816617310163) | 面外平移/转动会让 2D-DIC 场量失真并降低 VFM 参数稳定性；立体 DIC 可减弱该风险 | 正式路线采用 3D 立体 DIC；用空间标定、刚体和面外误差指标作为 VFM 前置闸门，2D 只作历史基线对照 | 铝材示例；这里只迁移误差机制 |
| Walker et al., 2022, [Biaxial VFM with missing edge data](https://www.tandfonline.com/doi/abs/10.1080/15376494.2021.1979138) | DIC 噪声和试样边缘缺失会影响 VFM；多加载步最小二乘和边界处理可以减弱影响 | 对 ROI 边缘掩膜、噪声扰动和多加载步识别做敏感性分析 | 硅橡胶案例；不移植材料参数 |
| Wang, Pierron & Thomsen, 2013, [PVC foam parameters by DIC + VFM](https://eprints.soton.ac.uk/357205/) | 加载构型和虚场可通过数值优化降低噪声/缺失数据敏感性 | 把加载路径、有效观测区和虚场作为联合设计变量；先做无量纲筛选 | 泡沫材料和 Arcan 夹具与本设备不同 |
| Hou et al., 2018, [Cruciform specimen for large plastic strain](https://doi.org/10.1088/1742-6596/1063/1/012160) | 中心区均匀性、夹臂/槽端破坏位置和多双轴力比应一起评价 | 评价 PA12 几何候选时同时看中心场量、夹臂安全和边界力，不只看最大载荷 | 金属板试样；其几何数值不作为 PA12 设计值 |
| Mazzoleni et al., 2015, [Gaussian pre-filtering and DIC uncertainty](https://doi.org/10.1016/j.optlaseng.2014.08.004) | 散斑频谱、滤波、subset、step 和应变窗口存在精度—分辨率折中；系统偏差与随机不确定度要分开 | 用 MatchID 2019 对当前散斑和图像做静态/刚体/已知位移小扫描；记录参数而不是照搬论文参数 | 其示例值只是预试验起点 |
| Schneider & Kumar, 2020, [PA12 processed by SLS](https://www.sciencedirect.com/science/article/pii/S0142941819320860) | PA12 的成形方向可能造成明显力学差异；本构参数需要结合材料来源和方向 | 在 PA12 文献矩阵中保留成形方式、方向、批次和重复性字段 | 该研究是 SLS PA12；本项目材料路线仍待确认 |

### 1.3 由论文共同支持的研究主线

多篇来源共同指向同一个可检验的核心：

```text
整体力—位移只能给出边界响应
DIC 给出全场运动和应变
VFM 把两者通过虚功平衡连接起来
```

因此本项目最适合先验证：

> 在同步、边界和 DIC 质量可信时，加入全场信息是否能改善 PA12 本构参数的可辨识性、重复性和独立路径预测。

同步误差、3D 空间标定/面外运动、ROI 边缘缺失和单位错误不是附属问题，而是决定“参数对上”是否有物理意义的质量闸门。

## 4. 接下来按什么顺序做

1. **论文证据**：把新增的 VFM、DIC 误差和 PA12 论文优先取得全文，逐篇补充方法矩阵中的页码、图表和字段。
2. **数据接口**：取得一份真实 MatchID 2019 导出和同一试验的力/位移文件，完成 `data_schema.csv` 和字段映射。
3. **L0 基线**：在 Python 或 MATLAB 中实现线弹性 VFM 小流程，先查单位、边界项和同步，不追求复杂模型。
4. **独立验证**：确定一条不参与拟合的加载路径或一个独立试样，冻结参数后再预测。
5. **正式选题**：只有 L0、同步和 DIC 预检通过后，才决定是否升级到弹塑性、超弹性或黏弹性，并确定小论文标题。

下一次你提供一小段 MatchID 导出、力/位移数据和试样厚度后，就可以从第 2 步开始，不必再等待相机品牌或完整设备档案。
