# CONSTITUTIVE MODELS｜M0–M7 模型阶梯与决策树

模型选择必须由数据筛选和留出预测驱动，不能先验指定 J2 + Voce。

## 1. 模型阶梯

| 模型  | 形式                      | 需要回答的问题              | 额外参数/证据                   | 当前准入     |
| --- | ----------------------- | -------------------- | ------------------------- | -------- |
| M0  | J2 + 线性等向硬化             | 最小弹塑性基线能否解释首篇固定速率数据？ | 弹性、屈服、线性硬化；需稳定塑性段         | 首选基线     |
| M1  | J2 + Voce               | 硬化是否具有饱和/非线性？        | Voce 参数需由塑性段激活            | 候选       |
| M2  | J2 + Swift              | Swift 幂律是否优于 Voce？   | 需明确塑性应变、屈服平移和参数化，避免奇异相关   | 候选       |
| M3  | 率相关 J2 + Voce 或 Perzyna | 速率差异是否超出噪声/批次离散？     | 同材料/方向/路径的多个实际时间历史、率标签和重复 | 阻塞       |
| M4  | Hill48 + Voce           | 打印方向是否要求各向异性屈服？      | 多方向屈服/塑性数据；至少需可比较的方向信息    | 阻塞，首篇不纳入 |
| M5  | 率相关 Hill48 + Voce       | 率与各向异性是否耦合？          | M3 与 M4 的证据同时满足           | 阻塞       |
| M6  | 黏弹–黏塑                   | 是否有恢复、松弛、保持段和历史效应？   | 短/长时间数据、循环/松弛/恢复、时间尺度     | 阻塞       |
| M7  | 各向异性塑性 + 损伤             | 峰后局部化/损伤是否是主要机制？     | 峰后全场、失效模式、重复、损伤参数可辨识数据    | 阻塞       |

## 2. 当前模型筛选事实

目前还没有用已验证的真实全场和时间轴完成以下判断：初始弹性是否明显线性、塑性是否线性、Voce/Swift 谁更优、速率差异是否显著、XY/XZ 是否需要各向异性、是否存在可识别恢复/松弛、是否存在可建模损伤。因此这些只能列为筛选任务，不能写成既定结果。

现有近似应力—应变曲线来自端点配对和估计面积，只能做趋势审查，不足以承担模型选择结论。

## 3. 决策树

```text
真实字段/时间/单位/几何/边界力完整？
├─ 否 → 不做真实 VFM；转数据链审计与字段解析
└─ 是
   └─ Virtual Experiment 无噪声真参数可回收？
      ├─ 否 → 停止，排查本构积分、坐标、单位、边界、虚场和优化器
      └─ 是
         └─ 固定速率 M0/M1/M2 比较
            ├─ M0 足够且留出不劣 → 选 M0
            ├─ 非线性硬化有稳定证据 → 比较 M1/M2，按留出与复杂度选
            └─ 速率差异经同条件重复确认 → 开放 M3
               └─ 多方向屈服差异经独立数据确认 → 开放 M4/M5
                  └─ 松弛/恢复数据充分 → 才考虑 M6
                     └─ 峰后场和损伤证据充分 → 才考虑 M7
```

## 4. 模型准入与停止规则

- 新模型必须同时改善至少一个独立留出指标或解释已确认物理现象，且不能让参数区间和 FIM 条件性不可接受。
- 训练误差下降但留出误差不降时，不增加模型复杂度。
- 参数强相关、多个初值落入不同解且预测不稳定时，模型标记为“不可识别”，不是“优化未调好”。
- MJF 文献模型不能直接转为 SLS PA12 参数或物理结论。
