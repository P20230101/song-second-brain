# VFM 软件识别闭环与本构参数验收

## 先说清楚“对上”是什么

可以用软件根据双轴试验数据反演本构参数，但“对上”不能只指一条力—位移曲线被拟合出来。VFM 的合格结果至少要同时满足：

```text
虚功残差足够小
    + 参数在未参与拟合的加载路径/试样上仍能预测
    + DIC 全场的空间残差没有明显系统结构
    + 参数对同步、噪声、ROI 和前处理扰动不过度敏感
    + 单位、边界力、厚度和时间轴全部可追溯
```

如果只优化一个目标函数、只用同一批帧回代、只展示“拟合曲线”，得到的可能是过拟合参数，不是可发表的材料本构。

## 1. VFM 的软件输入

### 1.1 每个 DIC 帧的场量

来自 MatchID 2019 的导出文件至少要能映射出：

```text
frame_id
t_image 或可映射到机器时钟的时间
x, y（统一单位）
u, v（位移，统一单位）
应变分量（若由 MatchID 导出）
相关质量/有效点标记
ROI 和边缘缺失掩膜
```

如果只导出应变、不导出位移，需要记录应变计算窗口和滤波设置；如果只导出位移，则在求解器中计算应变时必须记录平滑/差分规则。不能把不同规则产生的应变混在同一批识别中。

### 1.2 试验机边界输入

```text
machine_sample_id
t_machine
F_x, F_y（方向、符号和单位）
u_machine_x, u_machine_y（方向、符号和单位）
边界牵引/加载区域定义
厚度 h
```

双轴力传感器给出的通常是合力。若 VFM 需要边界牵引分布，必须说明“由合力换算牵引”的假设、受力宽度/厚度和适用边界；不能自动把合力当作每个边界点的局部应力。

### 1.3 时间和事件输入

```text
event_id
trigger_id
frame_id
machine_sample_id
t_image
t_machine
sync_residual
```

每一帧用于 VFM 的力和位移都必须能回到唯一的机器采样或明确的插值区间。标称相机频率和 DAQ 频率相同，不等于时间轴已经同步。

## 2. VFM 的核心计算

在准静态、平面应力假设成立时，对每个加载时刻 `t_k` 和虚场 `u*` 建立虚功残差：

```text
r_k(θ) = 内部虚功(σ(ε(x,t_k); θ), ε*)
         − 边界外力虚功(F_x, F_y, u*)
```

如果试验进入明显动态区，平衡式需要另外核对惯性项：

```text
r_k(θ) = 内部虚功 − 边界外力虚功 − 惯性虚功
```

不能在动态数据上默认使用准静态 VFM，也不能因为机器宣传的最高速度就直接加入惯性项；是否需要动态项由速度、加速度、采样和残差证据决定。

软件的基本流程是：

```text
MatchID 场量 + 试验机边界力
        ↓
统一坐标、单位、厚度和时间轴
        ↓
有效 ROI / 边缘掩膜 / 虚场定义
        ↓
给定本构模型 θ，计算 σ(ε; θ)
        ↓
计算各帧/各虚场的 r_k(θ)
        ↓
线性求解或有界非线性最小二乘
        ↓
输出参数、残差、协方差/区间和敏感度
        ↓
独立路径与扰动数据验证
```

## 3. PA12 的模型选择顺序

不要先凭“VFM 很高级”指定一个复杂模型。先用最简单的模型检查测量链，再按数据中可重复观察到的现象升级：

| 层级 | 候选模型 | 何时进入 | 主要用途 |
|---|---|---|---|
| L0 | 小应变线弹性（各向同性或正交各向异性） | 低载荷近线性区 | 检查坐标、单位、边界力、DIC 和 VFM 积分是否自洽 |
| L1 | 有限应变弹塑性/硬化模型 | 出现屈服、不可逆变形或大应变 | 识别屈服/硬化参数，验证独立加载路径 |
| L2 | 超弹性模型 | 试验表现为可恢复的大变形，且文献/卸载证据支持 | 比较不同能量函数和虚场敏感性 |
| L3 | 黏弹性/黏塑性模型 | 加载速率、保持时间或循环历史显著影响响应 | 需要额外的时间项、历史变量和更严格的时间轴 |

PA12 的具体层级必须由你的加载速度、应力—应变历史、卸载/保持段和文献证据决定。VFM 不是自动判别材料模型的软件；模型错了，优化仍可能给出一组看似合理的数。

## 4. 拟合与验证必须分开

### 4.1 拟合集

用于求 `θ` 的数据只包含预先声明的帧和加载路径。记录：

```text
fit_frame_ids
fit_load_paths
fit_ROI
fit_virtual_fields
objective_definition
weights / uncertainty model
optimizer and bounds
initial values / multistart rule
```

### 4.2 验证集

至少保留一种不参与拟合的证据：

- 独立双轴加载比例或加载路径；
- 独立 PA12 试样；
- 同一试验中保留的后段/卸载段（模型适用时）；
- 不同 ROI 或边缘掩膜；
- 只用整体力—位移的基线对照。

验证时不重新调整参数。否则仍然是拟合，不是验证。

## 5. “对上”的最小验收表

| 检查 | 合格含义 | 不合格时怎么做 |
|---|---|---|
| 量纲/符号 | 力、位移、坐标、厚度、应变和应力单位一致；拉压符号明确 | 返回数据映射，不进入优化 |
| 时间映射 | 每帧对应唯一机器采样/插值区间；残差可计算 | 返回同步验证，不能靠曲线手动平移 |
| DIC 质量 | 静态/刚体场无未解释系统应变；有效点和边缘掩膜固定 | 返回 MatchID 前处理/2D 假设检查 |
| 边界项 | 两方向合力、受力区域和牵引假设可追溯 | 补边界定义或降低结论等级 |
| 训练残差 | 虚功残差相较基线有解释性的下降 | 检查模型、虚场、边界和数据，不盲目换优化器 |
| 独立预测 | 未参与拟合的路径/试样仍能预测整体和场量趋势 | 不能称为模型已验证；分析可辨识性和外推失败 |
| 稳定性 | 对合理噪声、ROI 和同步扰动，参数变化有界且可解释 | 报告敏感性，必要时返回测量链 |
| 重复性 | 独立试样之间的差异与测量不确定度和材料离散性相容 | 不能把差异隐藏为异常值 |

## 6. 软件实现选择

### 第一阶段：本地 Python 或 MATLAB VFM 求解器

MatchID 2019 负责图像相关和场量导出；VFM 求解器可以在 Python 或 MATLAB 中实现。第一版只需要：

```text
读取统一 CSV/Mat 文件
单位和字段检查
帧—机器采样映射
ROI/掩膜
虚场和积分权重
一个 L0 基线模型
残差最小二乘
独立验证和报告生成
```

不需要先购买或安装大型商业有限元软件。Abaqus/Ansys 可在后续作为正问题/FEMU 交叉验证工具，而不是 VFM 识别的必要前置条件。

### 第二阶段：增加模型和敏感度分析

在 L0 流程通过后再增加：

- L1/L2/L3 本构模型；
- sensitivity-based virtual fields；
- 多加载步联合最小二乘；
- 参数协方差、bootstrap 或 Monte Carlo；
- 2D/3D 或面外运动对比；
- VFM 与 FEMU/整体曲线的交叉验证。

## 7. 固定文件接口

拿到真实 MatchID 2019 导出样例后，按下列文件组织，不覆盖原始文件：

```text
实验/PA12-双轴-DIC-VFM/vfm/
├─ README.md
├─ data_schema.csv          # 字段、单位、来源、缺失规则
├─ vfm_config.yaml          # 模型、虚场、ROI、权重、拟合/验证划分
├─ run_manifest.json         # 输入文件、版本、时间、运行参数
├─ input/                    # 只读的派生输入，不放原始 PDF/图像
├─ scripts/                 # Python/MATLAB 求解和绘图
└─ results/
   ├─ identification_report.md
   ├─ validation_report.md
   ├─ parameter_table.csv
   ├─ residuals.csv
   └─ figures/
```

原始图像、机器原始数据和 MatchID 工程文件继续保存在实验数据区，不复制成多个“最终版”。

## 8. 当前最短路径

你现在不需要先决定复杂本构，也不需要先知道相机品牌。下一步只要给出一份小样本：

1. 一段 MatchID 2019 导出 CSV/Mat（包含字段名和几行数据）；
2. 同一试验的双轴力/位移 CSV；
3. 试样厚度、坐标单位和两方向符号；
4. 哪些帧对应哪个机器采样，或一组可识别的触发事件；
5. 试验是准静态还是有明确的高速/惯性效应。

收到后先实现 L0 基线和字段映射，输出：

```text
字段映射报告
单位/符号审计
同步残差报告
L0 参数试算
训练/验证划分
整体响应与场量残差图
```

只有 L0 能闭环，才值得把时间花在更复杂的本构模型上。

## 9. 结论

你的想法可以落地为“软件从 DIC + 边界力反演本构参数”，而且 VFM 很适合做这条主线；但论文成果不应定义为“参数能对上”，而应定义为：

> 在明确同步、边界、DIC 质量和单位链的条件下，某一候选本构模型能够由全场数据识别，并在未参与拟合的加载路径/试样上以可报告的不确定度重现实验响应。

这一定义会把“高级算法”转成可审稿、可复现、可继续扩展的工程力学结果。
