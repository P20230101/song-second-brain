# 双轴-DIC-VFM｜方法比较与候选创新点

本页由首轮 Semantic Scholar + arXiv 检索和 5 篇公开 PDF 的 MinerU 非 OCR 全文解析形成。它只总结已在全文中看到的方法关系；PA12 制备、设备真实参数和正式试验方案暂不在本页假定。

## 当前研究状态

- MatchID 版本已由用户确认是 **2019**；后续自动化只依赖该版本实际可导出的字段，不假设新版本接口。
- 研究方法主线暂定为：双轴加载 → MatchID 2019 3D 立体 DIC 全场三维位移/应变 → 同步边界力/位移 → VFM 参数识别或模型验证。袁文件夹中的 2D 工程只作为历史处理链和误差对照。
- 当前证据适合建立方法路线和候选创新点，不足以确定最终本构模型、加载路径或 PA12 参数。

## 方法路线的固定拆分

### A. 测量层

MatchID 2019 需要保存：原始图像序列、标定、ROI、subset/step、应变窗口/滤波、相关质量、坐标系和导出字段。现有 MatchID 官方资料显示其工具链包含同步触发、力/加速度等外部信号采集和 CSV/MAT/HDF 等导出能力，但这些是当前产品资料，不能当作 2019 版本已具备的事实；需由用户在实验室确认。[MatchID 软件能力说明](https://www.matchid.eu/software)

### B. 同步层

VFM 所用每个图像帧必须有唯一的力/位移时刻、触发事件和同步残差。相机帧率与 DAQ 频率可以不同；频率相同也不能替代时间映射。同步误差应作为数据质量字段进入每个试验目录。

### C. 识别层

1. 先用整体力—位移和 DIC 全场数据做独立一致性检查。
2. 根据候选本构的线性/非线性结构，选择直接线性解、梯度优化、GA 或其他方法；不先把算法写死。
3. 对虚场、DIC 噪声、边缘缺失、ROI 和时间帧做敏感性分析。
4. 用不同应力比或保留加载路径做验证，报告参数置信度/重复性，而不是只报告一条拟合曲线。

## 候选创新点（待验证，不是结论）

| 候选 | 可检验差异 | 最小证据 |
|---|---|---|
| 1. 双轴应力比对 VFM 参数可辨识性的影响 | 同一试样/材料路线下，对比等双轴与非等双轴路径的参数稳定性、残差和独立路径预测 | 通过同步闸门的多路径试验 + 统一 DIC 参数 + 交叉验证 |
| 2. MatchID 2019 3D DIC 标定/边缘缺失对 VFM 的影响 | 以真实三维导出场量做标定残差、ROI、边缘剔除、滤波和应变窗口敏感性分析，量化参数漂移；2D 结果仅作历史基线对照 | 原始图像、导出场、标定与处理参数版本和 VFM 参数不确定度 |
| 3. VFM 与整体力—位移/FEMU 的交叉验证 | 比较只用整体曲线、只用全场、联合目标的预测能力和计算代价 | 同一数据分割、独立验证路径、误差和计算时间记录 |
| 4. 准静态到动态边界的识别分流 | 验证何时必须在平衡方程中保留惯性项，防止把动态数据套入准静态 VFM | 触发同步、速度/加速度记录、平衡残差和分流判据 |

候选 1–4 只有在设备通道和预试验数据可用后才进行优先级排序。材料制备暂不作为当前研究瓶颈。
