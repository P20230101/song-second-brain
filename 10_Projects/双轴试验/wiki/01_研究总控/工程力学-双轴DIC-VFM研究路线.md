# 工程力学｜双轴试验-DIC-VFM研究路线

本页把双轴拉伸/压缩、DIC 和 VFM 固定为一条分阶段科研路线。它是执行规则，不是已经得到的实验结论。任何材料、尺寸、载荷和本构模型，都必须经过设备资料、文献和预试验确认。

## 总体链路

```text
研究上下文
  → 文献捕获与质量核对
  → 文献矩阵与研究缺口
  → 研究问题/假设
  → 设备与试样可行性
  → 同步采集验证
  → DIC/VFM 预试验
  → 正式双轴试验
  → 力-位移 × 全场应变 × VFM 交叉验证
  → 小论文
  → 可复用扩展后形成大论文主线
```

## 固定阶段与闸门

### 阶段 0：研究上下文和设备能力

**目标**：把已知边界和未知边界分开。

**必须完成**：

- 读取并更新 `wiki/01_研究总控/研究上下文.md`；
- 获取设备说明书、夹具资料、校准记录和 DIC 配置；
- 明确参数海报中的 0–10 kN 是总额定力还是每轴额定力；
- 用设备说明书和校准记录解决“0–100 mm”与参数海报“±150 mm”的行程信息差异；
- 明确双轴通道是否独立、同步、可拉可压。
- 明确力/位移数据采集与相机的共同触发、时间戳和数据导出能力。

**闸门**：设备、夹具和安全边界没有核对前，不设计正式载荷矩阵，不声称设备能够完成目标试验。

**输出**：

```text
raw/设备/设备规格与校准记录.md       # 原始说明或核对摘要
wiki/01_研究总控/研究上下文.md                    # 更新后的稳定边界
研究报告/日报/YYYY-MM-DD.md           # 未决问题和确认记录
```

### 阶段 1：文献捕获与方法学习

**目标**：先知道别人如何做双轴试验、DIC 和 VFM，再决定研究缺口。

使用三组检索方向：

```text
双轴加载对象 + material response / constitutive behavior
双轴加载对象 + digital image correlation / full-field strain
双轴加载对象 + virtual fields method / parameter identification
```

第一轮只捕获 5–10 篇种子论文。每篇固定提取：

- 材料、试样几何和边界条件；
- 拉伸/压缩方向及加载路径；
- 机器容量、位移/力控制和同步方式；
- DIC 相机、标定、散斑、空间分辨率和应变计算；
- VFM 的本构假设、虚场、输入场量和识别参数；
- 重复试验、验证路径、误差指标和局限性。

**闸门**：至少有多个来源对同一方法限制或验证不足给出可核对证据，才进入研究问题设计。

**输出**：

```text
raw/参考文献/<项目名>/PDF原件/
raw/参考文献/<项目名>/download_manifest.json
wiki/<项目名>-文献矩阵.md
wiki/<项目名>-方法学习笔记.md
```

### 阶段 2：研究问题、假设和贡献

**目标**：把文献缺口转成 2–4 个可检验问题。

每个候选问题都必须写清：

- 缺口来自哪些论文、哪一节/表/图；
- 你的新增内容是材料、加载路径、DIC 信息、VFM 识别、验证方式还是组合；
- 所需数据是否能由现有设备和 DIC 系统获得；
- 什么结果支持假设，什么结果会推翻假设；
- 小论文的最小贡献是什么，大论文如何在此基础上扩展。

**闸门**：不能用“研究较少”作为唯一创新依据；没有可获得数据和可比较基线的问题不进入正式试验。

**输出**：

```text
wiki/<项目名>-研究问题与假设.md
wiki/<项目名>-创新候选与证据链.md
```

### 阶段 3：设备、试样和 DIC/VFM 可行性

**目标**：证明试验能测、数据能同步、参数能识别。

固定检查顺序：

1. 试样几何与夹具适配；
2. 双轴加载方向、控制量和边界条件；
3. 力/位移通道的采样和同步；
4. 相机帧—试验机采样的唯一映射、触发偏移和时钟漂移；
5. DIC 视场、散斑、标定和照明；
6. VFM 所需场量、虚场和边界条件；若进入动态工况，另行验证惯性项与加速度场处理；
7. 小载荷预试验和重复性检查；
8. 安全工作区间与停止条件。

**闸门**：预试验不能稳定得到可用力—位移、DIC 场量和同步时间轴时，返回调整，不进入正式试验。

**输出**：

```text
实验/<项目名>/README.md
实验/<项目名>/protocols/预试验方案.md
实验/<项目名>/calibration/设备与DIC标定记录.md
实验/<项目名>/calibration/帧-采样映射.csv
实验/<项目名>/data/README.md
```

### 阶段 4：正式双轴试验

**目标**：按预注册/确认的加载矩阵采集独立重复。

固定记录：

- 试样编号、材料批次、几何尺寸和厚度；
- 加载路径、控制模式、速率和停止条件；
- 机器力/位移原始数据；
- DIC 原始图像、标定文件和处理参数；
- 每一张参与分析图像的帧编号、相机时间、对应试验机时间/样本、触发事件与同步残差；
- 环境、操作者、日期和异常事件；
- 真实独立试样数量，避免把重复帧或重复扫描当成独立重复。

**闸门**：没有完整原始数据和元数据的试样不进入最终统计或 VFM 结论。

### 阶段 5：三路数据交叉验证

固定比较三条证据链：

```text
机器力/位移 → 整体响应
DIC 位移/应变 → 局部与全场响应
VFM 结果 → 本构参数或模型一致性
```

比较时必须保持：

- 同一试样编号和时间轴；
- 同一加载路径和边界条件；
- 同一参数定义和单位；
- 明确哪些指标可以比较，哪些只能定性对照；
- 报告误差、重复性和不确定性，不只报告最优结果。

**输出**：

```text
实验/<项目名>/results/力-位移分析.md
实验/<项目名>/results/DIC场量分析.md
实验/<项目名>/results/VFM识别与验证.md
实验/<项目名>/results/交叉验证.md
```

### 阶段 6：论文分层

**小论文**：选择一个最小、可闭环的问题，例如一类材料、一个加载路径或一个方法验证问题；要求数据闭环、基线清楚、结论不过度外推。

**大论文**：只有小论文流程稳定后，才扩展材料、加载路径、参数识别或误差分析，并保留小论文作为可复核的基础模块。

**输出**：

```text
wiki/<项目名>-论文大纲.md
wiki/<项目名>-证据矩阵.md
实验/<项目名>/manuscript/图表与结果索引.md
```

## 每日执行固定格式

每天讨论后，只推进一个阶段，并在每日闭环页记录：

1. 当前研究状态；
2. 已知证据；
3. 来源缺口；
4. 当前研究阶段；
5. 拟执行的下一阶段；
6. 下一阶段会生成哪些文件；
7. 需要用户确认的问题。

没有确认就停在当前闸门，不跨阶段生成实验代码或正式结论。

## 当前阶段结论

当前处于阶段 0：选题与设备能力核对。下一步不是直接做正式双轴试验，而是先补齐设备/夹具/DIC/VFM 条件，并启动第一轮种子论文矩阵。

同步采集的具体规则见[双轴-DIC-VFM｜同步采集与预试验方案](../02_实验与VFM/双轴-DIC-VFM-同步采集与预试验方案.md)。
