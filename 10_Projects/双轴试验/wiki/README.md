# 双轴试验 Wiki｜导航

Wiki 页面已经按研究用途分成五组。日常只从下面的入口进入，不再在本目录平铺查找。

## 先看

- [[00_一页总览]]：研究主线、当前闸门和下一步。
- [[01_研究总控/README]]：题目、证据、决策和质量门。
- [[02_实验与VFM/README]]：DIC、同步、VFM 和真实数据。
- [[03_仿真与验证/README]]：Abaqus、合成 FE/VFM 和验证。
- [[04_文献与工具/README]]：文献矩阵、全文证据和工具流程。
- [[05_结果与论文/README]]：审查后的结果图、讲解和论文材料。

## 五个目录

| 目录 | 用途 |
|---|---|
| `01_研究总控` | 研究背景、问题定义、阶段决策、项目总览 |
| `02_实验与VFM` | DIC、照片—力同步、VFM 输入和参数识别 |
| `03_仿真与验证` | 试样/夹具仿真、Abaqus、模型验证 |
| `04_文献与工具` | 文献、MinerU、Semantic Scholar、数据审计 |
| `05_结果与论文` | 真实结果、图集、PPT 和论文交付 |

## 固定边界

- 原始照片、CSV、DAT、PDF、MatchID/Abaqus 工程和脚本留在原目录。
- 没有共同时间戳或硬件触发证据时，照片—力映射只能标记为候选。
- 每晚 21:00 只整理当天新增或修改的 Markdown，不混入历史日期。
