# 科研日报｜2026年9月11日

## 3. 来源缺口

- [ ] 双轴机说明书：实际行程、通道独立性、载荷传感器型号、采样时钟和触发 I/O。
- [ ] 相机与 MatchID：型号、镜头、有效分辨率、帧率、曝光、标定、subset/step/滤波/应变窗口。
- [ ] PA12：粉末牌号、SLS 工艺、取向、厚度、调湿状态、十字形试样几何和重复数量。
- [ ] VFM：目标本构形式、虚场选择、边界力引入方式与不确定度评估。

## 4. 当前研究阶段

- 当前闸门：完成设备—相机—DAQ 共用触发与帧—力映射预试验设计。
- 通过证据：已有可参考的设备与 PA12-DIC 基线；研究范围已排除 FDM-PLA 晶格压溃路线。
- 尚未验证：实际装置的触发接口、同步残差、面外运动控制、PA12 样品来源与 VFM 识别稳定性。

### 可复用结论

- 相机帧率和力采样率不必相等，但 VFM 所用每一帧必须能映射到确定的力/位移时刻。
- 两篇论文分别承担设备验证与 PA12-DIC 基线的证据角色，不可互相替代。
- MinerU 解析结果已具备图文分离材料，但关键图表尚未逐项与原 PDF 对照核验。
- 首轮方法证据支持四类待验证差异：应力比对可辨识性、MatchID 2019 2D DIC 误差/边缘缺失、VFM 与整体曲线/FE体系交叉验证、准静态/动态方程分流。

### 不应升级为结论的内容

- 当前设备与文献中尚未证实的相机帧率、同步误差、DIC 参数与 VFM 本构类型。
