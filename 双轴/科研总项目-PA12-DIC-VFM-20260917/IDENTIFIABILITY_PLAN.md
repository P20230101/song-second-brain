# IDENTIFIABILITY PLAN｜参数可辨识性、加载路径与模型形式误差

## 1. 要区分的概念

- 优化器收敛：数值过程停止；
- 参数回收：`θidentified` 接近独立真值 `θtrue`；
- 局部可辨识：敏感度矩阵在尺度统一后有足够秩；
- 全局可辨识：多初值/profile/bootstrap 没有等价解族；
- 模型正确：不仅拟合已见数据，还能预测未见路径。

本项目不以其中任何单项替代整体证据。

## 2. 观测与灵敏度

按数据来源建立观测向量：

`y = [整体 Fx,Fy；边界位移/反力；DIC u,v 或 exx,eyy,gxy；VFM 各帧残差]`。

对参数 `θ` 计算尺度一致的灵敏度：

`S_ij = ∂y_i/∂θ_j`，再根据测量协方差或明确噪声假设构造 `F = Sᵀ W S`。

每次报告：参数尺度、FIM 秩、缩放条件数、参数相关矩阵、最小奇异值、路径/空间窗口和噪声假设。当前已有 `cond≈28.73` 只属于项目 L0 synthetic Q 矩阵基线，不属于 PA12 实验可辨识性结论。

## 3. 必做对照

| 对照 | 目的 |
|---|---|
| curve-only vs field | 证明 VFM/全场是否带来额外信息 |
| uniaxial vs biaxial | 检验双轴是否激活不同参数 |
| uniaxial + biaxial vs 单独各自 | 检验联合识别是否降低相关性 |
| M0 vs M1 vs M2 | 检验模型形式误差与复杂度代价 |
| seen path vs held-out path | 区分拟合能力与跨路径预测 |
| independent trial vs frame split | 排除伪独立验证 |

## 4. 稳定性分析

- 多初值：LHS 或预定义物理范围，保存全部收敛和失败解；
- profile likelihood：逐参数固定并重优化，观察平坦方向和多解；
- bootstrap：以试样/路径为重采样单位，不以帧独立重采样替代试样重复；
- 噪声：DIC 位移/应变空间噪声、力噪声、边缘掩膜、采样稀疏和时移分别施加；
- 初值敏感性：比较参数和留出预测，而不是只比较最终目标值；
- 模型形式误差：用一个生成模型、另一个识别模型，记录偏差与错误自信；
- 空间分辨率：原始网格、下采样、应变窗口和边缘剔除；
- 时间分辨率：帧稀疏、延迟和时钟漂移情景。

当前 `XY` 端点时移表是 hypothetical scenario，不是置信区间，后续报告必须保留这个区分。

## 5. 加载路径 DOE

对 synthetic/virtual 路径 `1:0`、`1:0.25`、`1:0.5`、`1:0.75`、`1:1`，比较：

- 单路径和联合路径的 FIM；
- 参数激活图和相关性；
- 条件数/最小奇异值；
- 给定噪声预算下的参数误差；
- 对未见路径的预测误差。

只有当路径信息增益在多个真值和噪声情景下稳定，才可提出“某双轴比例更适合识别”的结论；不能只由一个 synthetic 真值决定。

## 6. 最低交付结果

参数回收表、multi-start 分布、objective landscape、灵敏度热图、参数相关矩阵、FIM 条件数、noise–parameter error 曲线、路径比例信息量图和留出路径误差表必须同时存在，才可声称完成可辨识性分析。
