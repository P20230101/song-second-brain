# PA12 M0–M2 合成 FE–VFM 基线

## 当前结论

这是通用 synthetic virtual experiment，不是 PA12 实测、文献标定或当前试样参数。

- M0（线性等向硬化）、M1（Voce）和 M2（Swift）均由 Abaqus 独立生成场量和四侧反力。
- UX 与 EQ 用于识别，R05 整条路径完全留出。
- 无噪声正确模型的最大参数相对误差分别为 `1.42e-5`、`2.34e-4`、`1.29e-3`；R05 虚功误差分别为 `6.00e-6`、`2.12e-6`、`1.92e-5`。
- 9/9 个 ODB 已由 Abaqus Python 以只读方式打开并逐帧抽取；每个含 23 帧、692 个 CPS4R 单元和 `E/S/PEEQ/RF`。
- 13 项本地回归测试通过。M0 的 20-start 固定种子 LHS 已全部收敛；M1/M2 多初值、噪声和模型形式误差仍在计算。

## Gate 边界

- synthetic Gate 3/4：通过；证明的是 FE–VFM 接口和通用参数回收。
- synthetic Gate 5：M0 部分通过，M1/M2 尚未完成。
- Gate 6/7：尚未通过；仍需噪声稳健性、FIM/条件数和路径信息增益。
- 真实 PA12：仍受 MatchID `.dat` 字段语义、有效掩膜、图像—力同步和四通道边界力契约约束，不能接入真实 VFM。
