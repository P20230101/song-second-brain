## 研究主线

**确认真实数据 → 对齐照片与力 → 运行 DIC/VFM → 识别本构 → Abaqus 验证 → 写论文。**

目录里的 `01/02/03` 是阅读顺序；长文件名是历史记录，不要求全部阅读。

## 五个目录

| 目录 | 用途 |

| `01_研究总控` | 研究背景、问题定义、阶段决策、项目总览 |

## 固定边界

- 原始照片、CSV、DAT、PDF、MatchID/Abaqus 工程和脚本留在原目录。
- 没有共同时间戳或硬件触发证据时，照片—力映射只能标记为候选。
- 每晚 21:00 只整理当天新增或修改的 Markdown，不混入历史日期。
