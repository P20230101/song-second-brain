## 约定

- 正文使用简体中文；
- 文件名使用稳定、可读的中文名称；
- 内部链接使用标准 Markdown 相对链接；
- 来源性陈述链接到 `raw/` 中的对应资料；
- 正式页面必须登记到根目录的 [`index.md`](../index.md)；
- 原始 PDF、原始图像、机器原始数据和 MinerU 私有解析不因导航重排而移动或公开；
- 每天的新增工作写入当天日报和 `log.md`，不把不同日期的内容合并成无日期的大页面。
