# 参考文献原件

这里保存文献捕获流程下载的本地 PDF。目录结构为：

```text
raw/参考文献/<项目名称>/
├── PDF原件/
└── download_manifest.json
```

## 规则

- `PDF原件/` 是 Raw sources，只读保存；不要改写、重命名或删除已有文件。
- `download_manifest.json` 记录标题、作者、年份、来源、原文链接、PDF 链接、本地文件名和下载状态，是后续分析的入口。
- PDF 原件、清单和研究笔记分开维护；先确认原文，再写摘要、证据链和章节映射。
- 本目录默认被 Git 忽略，不上传到公开仓库，以免公开个人下载记录或没有再发布授权的论文文件。
- 下载命令和外部结果 JSON 格式见 [`wiki/文献捕获与筑巢.md`](../../wiki/文献捕获与筑巢.md)。
