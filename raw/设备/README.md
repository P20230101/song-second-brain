# 设备原始资料收集表

本目录只保存设备说明书、夹具图纸或照片、校准记录和实验室安全要求等原始资料。原始文件放入后只读，不改名、不改写；下面的表格用于核对，不替代设备原文。

## 首轮必须核对的项目

| 项目 | 需要从原始资料确认的内容 | 当前状态 |
|---|---|---|
| 设备型号 | 品牌、型号、控制器和软件版本 | 已有设备照片；型号待补 |
| 力值 | 参数海报为 0–10 kN；确认是总额定力、单轴额定力还是每个通道额定力 | 待补 |
| 行程 | 参数海报为 ±150 mm；此前口述 0–100 mm，确认执行器、夹具和试样有效变形的定义 | 待补 |
| 轴向能力 | 左右轴是否独立控制、是否同步、是否可分别拉伸和压缩 | 待补 |
| 控制模式 | 力控、位移控、应变控及切换方式 | 待补 |
| 采集通道 | 参数海报为 1 kHz；确认力、位移、时间、触发信号、采样率和导出格式 | 待补 |
| 速度 | 参数海报为 0–4 m/s；确认可用工作区间、载荷限制和安全边界 | 待补 |
| 夹具 | 双轴夹具结构、适配尺寸、对中和边界约束 | 待补 |
| 校准 | 力、位移和相机/DIC 标定日期与有效期 | 待补 |
| 安全 | 最大允许值、急停、保护罩和停止条件 | 待补 |

## DIC 资料

- 相机数量、型号、镜头和分辨率；
- 帧率、曝光、照明和同步触发；
- 相机硬件时间戳、触发输入/输出、触发延迟与时钟漂移；
- 标定板、空间标定和坐标系定义；
- 散斑制备、应变计算窗口和步长；
- 软件名称、版本和导出格式。

## VFM 资料

- 计划采用的二维/三维假设；
- 候选本构模型和待识别参数；
- 虚场构造方式、边界条件和输入场量；
- 参数识别的验证加载路径和误差指标。
