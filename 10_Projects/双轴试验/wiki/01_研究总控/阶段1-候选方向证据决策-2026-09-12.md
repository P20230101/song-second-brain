# 阶段 1｜候选方向证据决策

## 先给结论

本阶段不把“2D 还是 3D”写成创新点，而是把它拆成两个不同的工作层：

1. **`yuan` 复现基线：MatchID 2019 的 2D DIC。** 现有文件的工程头、`.mti` 和代表性 CSV 都指向 2D 处理链；因此第一步必须按原格式复现，验证图像—场量—力/位移的数据链能否闭合。
2. **正式设备校核分支：如果未来确有双相机/立体图像和空间标定，再做 3D DIC 校核。** 3D 用来量化面外运动和修正测量偏差，不自动等于更好的本构识别，也不能把缺少 `Z/W` 的旧 CSV 改称为 3D 数据。

因此，当前唯一可执行的小论文问题是：

> 在与 `yuan` 相同的 MatchID 2019 2D 数据格式下，帧—力/位移同步、ROI 边缘处理和 DIC 参数变化，会不会改变 PA12 双轴试验的 VFM 本构参数及独立路径预测？相比只用整体力—位移曲线，加入 2D DIC 全场是否增加可辨识性？

这是一个测量链和识别方法问题，暂不假定材料牌号、成形方式、加载速度、试样尺寸或最终本构模型。

## 1. 检索范围与证据边界

### 1.1 本轮纳入范围

- PA12/聚合物的单轴本构和大变形行为，尤其是 DIC 或反演识别；
- 双轴拉伸、十字形试样和非均匀场设计；
- 2D/3D DIC 的面外误差、空间标定、散斑和同步；
- DIC + VFM/FEMU 的参数可辨识性、噪声/边缘缺失和独立验证。

### 1.2 排除或降级规则

- 其他材料的参数、试样尺寸和加载速度只能作为方法线索，不能直接写成 PA12 事实；
- 只有题名或摘要而未取得正文的来源，标为“摘要级线索”，不直接支撑数值结论；
- 设备厂商页面只能说明软件可能具备的功能，不能代替 MatchID 2019 实机导出和实验室触发记录；
- 2D/3D 术语按实际输出字段判定：有 `Z/W`、空间标定和双视角证据才可称为 3D。

### 1.3 可复现检索式（2026-09-12）

## 2. 为什么 2D/3D 重要，但不是研究问题本身

### 2.1 2D DIC 可以作为有效基线的条件

当试样表面近似平面、相机光轴和观测平面固定、加载过程中面外位移/转动可证明足够小，并且只需面内位移/应变时，2D DIC 可以提供可用的面内场量。它的优点是标定、数据格式和后处理简单，适合先把 `yuan` 的历史链复现出来。

### 2.2 3D DIC 解决的是测量误差来源

Sutton 等的理论与同步实验显示，单相机 2D 测量对面外平移和转动敏感，误差会以 `ΔZ/Z` 等形式进入面内应变；立体系统通过空间重建测量三向位移，可显著降低这类误差。[Sutton et al., 2008](https://doi.org/10.1016/j.optlaseng.2008.05.005)

Zhang 等进一步直接比较了 2D-DIC 与特殊立体 DIC 进入 VFM 的结果：面外运动会降低 2D-VFM 参数稳定性，立体测量可改善稳定性，但该验证对象是铝合金，不是 PA12。[Zhang et al., 2018](https://www.sciencedirect.com/science/article/pii/S0143816617310163)

这意味着：对十字形 PA12 试样，如果存在弯曲、翘曲、颈缩或夹具不对中，3D 是质量校核；但必须同时承担空间标定、双相机同步、重建噪声和 `Z` 向不确定度的成本。3D 不是“按下按钮就能得到正确本构”的保证。

### 2.3 `yuan` 的版本事实

`yuan` 的代表性工程标记为 `MatchID Input file 2019.2.2`，`.mti` 标记为 `MatchID 2D-Version 19.2.2.0`，代表性 `Img000000.jpg.csv` 字段为 `x_pic,y_pic,u,v,r,sigma,correlationPath,ShapeIndex`，没有 `Z/W`。这些事实记录在 [yuan 仿真与实验数据深入分析](../04_文献与工具/yuan-仿真与实验数据深入分析-2026-09-12.md) 和 [MatchID 2019 字段映射](../../实验/PA12-双轴-DIC-VFM/03_MatchID2019字段映射.md) 中。

所以本项目采用固定分层：

| 层 | 数据与目标 | 当前是否执行 |
|---|---|---|
| 2D 复现层 | `yuan` 原始图像 + MatchID 2019 2D 工程 + `u/v` 全场 + 力/位移 | **立即执行** |
| 3D 校核层 | 双视角图像、空间标定、`X/Y/Z` 或 `U/V/W`、刚体检验 | 只有取得真实立体资料后执行 |
| 本构识别层 | VFM/FEMU 与整体力—位移的交叉比较 | 2D 链通过同步和质量闸门后执行 |

## 5. 阶段 1 的唯一执行问题与候选假设

### 5.1 主问题（P0）

> **RQ-1：** 在同一 PA12 试验和同一时间轴下，相比仅使用整体力—位移曲线，加入 MatchID 2019 2D DIC 全场是否能降低 VFM 本构参数的不确定度，并改善对另一加载路径的预测？

### 5.2 质量闸门（P0）

> **RQ-1A：** 固定时间偏移、丢帧和线性时钟漂移，是否会显著改变 VFM 参数或场量平衡残差，即使整体力—位移曲线看起来仍然正常？

### 5.3 后续扩展（P1）

> **RQ-2：** 当 3D 立体 DIC 可用时，面外校正相对于 `yuan` 2D 基线能否显著降低场量残差和独立路径预测误差？

RQ-2 现在只是可验证的扩展，不应在没有 3D 原始资料前写成正式研究结论。

### 5.4 可检验假设

- H1：同步偏移对 VFM 的影响大于对单条整体力—位移曲线的影响；
- H2：ROI 边缘掩膜和应变窗口会造成可测的参数漂移，且在非均匀双轴场中更明显；
- H3：全场信息只有在存在足够的空间异质性、正确边界牵引和独立路径验证时，才会体现为可辨识性提升；
- H4：若本项目面外运动小于测量不确定度，2D 基线与 3D 校核的参数差异应不显著；若面外运动不可忽略，3D 校核应降低系统性偏差。

这些是假设，不是已验证的创新点。

## 6. 最小可执行路线（按顺序，不跨阶段）

### 6.1 0A｜锁定一份 `yuan` 匹配试验包

只选一组同时具有以下文件的序列：

```text
原始图像序列（JPG）
对应的 .jpg.dat 或 .dat
MatchID 2019 工程（.m2inp / .mti）
至少一个 DIC 导出 CSV
机器力/位移记录（CSV/XLS 或可读导出）
```

不要先选文件夹名中的 `0.1/1/10` 作为速度或应力比；其物理含义待用户确认。

### 6.2 0B｜2D DIC 复现与平面质量闸门

1. 用原工程打开一份序列，保存实际工程参数：ROI、subset、step、应变窗口、滤波、单位和导出字段；
2. 做静态重复或刚体平移测试，报告位移均值、标准差、漂移和相关质量；
3. 对同一序列建立帧号、图像文件、DIC 行号、机器采样区间的一一映射；
4. 对帧偏移、丢帧、边缘掩膜和应变窗口做小规模敏感性扫描；
5. 只有当映射和质量指标通过，才把场量送入 VFM。

### 6.3 0C｜合成 FE 场先行，避免空等设备

在等待真实设备参数期间，用十字形二维平面应力 FE 场生成可控数据，注入已知的时间偏移、随机噪声和边缘缺失，验证：

```text
场量读取 → 边界力映射 → VFM/FEMU 识别 → 独立路径预测 → 误差报告
```

合成数据只验证软件接口和误差方向，不能冒充实验结果。

### 6.4 0D｜2D 基线通过后再决定 3D

启用 3D 的最小条件是：双视角原始图像、标定板/标定参数、相机同步或共同触发证据、可导出三向位移/应变、刚体检验结果。缺任一项，就保留 2D 基线并把 3D 记为待办，不伪造 3D 场量。

## 7. 评价指标与数据分割

同一试验内不得把连续图像帧当作独立试样。建议固定以下指标：

| 层 | 指标 |
|---|---|
| DIC | 相关质量、静态位移标准差、刚体应变、边缘缺失比例、应变场空间平滑性 |
| 同步 | 帧—采样残差、固定偏移、漂移斜率、丢帧数、插值方法 |
| 整体响应 | 力—位移 NRMSE、峰值/屈服点偏差、加载路径间一致性 |
| VFM/FEMU | 参数估计、置信区间或重复性、虚功/平衡残差、计算时间、独立路径误差 |
| 2D/3D 对照 | `U/V` 差异、面外 `W` 幅值、重建/标定残差及其对参数的敏感性 |

最小数据划分为：一条路径用于识别，另一条路径或独立试样用于验证；不能用同一连续帧同时宣称“拟合”和“验证”。

## 9. 需要用户确认的最小问题

1. `yuan` 中准备作为复现入口的具体试验目录是哪一个？能否同时提供图像、`.dat`、MatchID 工程和力/位移文件？
2. `yuan` 文件夹中的 `0.1/1/10` 分别代表什么物理量和单位？当前不作速度或应力比推断。
3. 你未来正式设备是否有两台相机、立体标定板和共同硬件触发？若没有，正式路线先按 2D 基线推进。
4. PA12 是 SLS、MJF、注塑板材还是其他来源？本阶段只需确认成形方式，不要求现在补齐制备细节。
5. 第一批可接受的加载范围是弹性/小应变，还是必须覆盖屈服、颈缩或循环/保持段？这决定先做弹性 VFM 还是增加黏弹/塑性分流。

可以写：

> 本研究首先复现与 `yuan` 数据一致的 MatchID 2019 二维 DIC 处理链，建立图像帧、DIC 场量与试验机边界数据的可追溯映射；在此基础上比较整体响应、全场 VFM 与有限元反演，并以独立加载路径验证识别结果。若立体图像和空间标定资料满足质量闸门，再将三维 DIC 作为面外运动校核分支。

不能写：

- “`yuan` 已经完成 3D DIC”；
- “3D 一定比 2D 得到更准确的 PA12 本构参数”；
- “VFM 已经识别出本项目 PA12 参数”；
- “某个试样尺寸、加载速度或材料参数就是最优方案”；
- “仅凭整体力—位移拟合即可完成本构验证”。
