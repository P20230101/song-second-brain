# 阶段 1｜研究问题决策与下一步

## 本页的作用

本页把 2026-09-12 的公开来源核查转成下一阶段可执行的选择。检索结果仍分为“全文/正式页面证据”和“摘要/题名级线索”；只有前者可以直接支撑方法结论，后者只能决定下一轮下载顺序。

当前建议：

```text
主线候选 B：整体力—位移 vs DIC 全场对 VFM 识别的贡献
质量闸门 A：同步误差和帧—力/位移映射敏感性
扩展候选 C：试样几何与双轴加载路径对场量/可辨识性的影响
```

这不是最终创新点，也不是正式论文题目；正式确定需要全文核验、设备/触发资料和低载荷预试验。

## 2. 当前研究问题排序

### P0｜主线候选 B：全场信息是否增加可辨识性

**研究问题草案**：

> 在同一 PA12 双轴加载试验和同一时间轴下，仅使用整体力—位移数据，与加入 MatchID 2019 DIC 全场位移/应变后相比，候选本构参数的可辨识性、重复性和独立路径验证误差是否改善？

**为什么先选它**：

- 直接回答“为什么必须做 DIC/VFM”，不是只做一条力—位移曲线；
- 可以形成基线（整体数据）和增强方法（全场数据）的清楚对照；
- 即使参数改善不明显，也能形成“适用边界/误差来源”的方法学结果；
- 不需要现在就把材料制备、相机品牌和所有加载路径铺开。

**最小结果包**：

```text
整体力—位移基线
DIC 全场位移/应变质量指标
VFM 参数识别结果
独立加载路径或独立试样验证
参数重复性和不确定度
三路结果的差异解释
```

### P0｜质量闸门 A：同步误差敏感性

**问题草案**：

> 帧—力/位移映射中的固定延迟、丢帧和时钟漂移，是否会在整体力—位移曲线看起来正常时，显著改变 VFM 参数或场量残差？

它不是另起一个与主线无关的题目，而是 B 的必要质量闸门。如果时间轴不可信，B 的比较没有解释力。A 至少需要：

- 共同触发或可追溯软件事件；
- `frame_id`、`machine_sample_id`、两个时间戳；
- 同步残差和丢帧记录；
- 对已知偏移/漂移的敏感性分析。

### P1｜扩展候选 C：几何与加载路径

**问题草案**：

> 试样中心区均匀性、夹臂/槽端应力集中和双轴加载路径变化，如何共同影响 DIC 场量质量和 VFM 参数可辨识性？

C 的工程意义大，但需要 FE 初筛、夹具尺寸和更多机时。它应在 B 的测量链通过之后进入大论文扩展，而不是现在阻塞小论文。

## 3. 不把什么写成结论

- 不把其他材料的试样厚度、圆角、槽形、加载速度或 VFM 参数直接移植到 PA12。
- 不把出版社摘要中的“更稳定”“更准确”改写成你设备上的已验证结果。
- 不把相机型号当作研究创新点；真正需要比较的是实际帧率、曝光、像素尺度、畸变、触发和时间轴。
- 不把同一试样的连续图像帧当成独立试样重复。
- 不在没有独立加载路径/独立试样时写“本构模型已验证”。

## 4. 下一阶段的固定执行顺序

### 阶段 1A：全文获取和证据矩阵

优先获取并用 MinerU（非 OCR）解析以下论文：

1. VFM + polymer / hyperelastic + DIC；
2. 2D-DIC 面外运动和误差；
3. 双轴试样边缘缺失和加载构型；
4. PA12 的本构、各向异性和双轴/多轴响应。

每篇都填入：

```text
材料与成形方式
试样几何与厚度
加载路径和边界力
DIC 类型、标定、散斑和参数
帧—力/位移同步方式
VFM 本构、虚场和优化器
重复试验与独立验证
误差、不确定度和局限性
```

生成：


### 阶段 1B：问题和假设页

把 B 和 A 写成两个相互关联、但可分别证伪的假设：

```text
H_B：在同步可信、DIC 质量达标时，全场输入相较整体力—位移基线
     能降低候选本构参数的不确定度或改善独立路径验证。

H_A：即使整体力—位移曲线变化不明显，时间错位/丢帧/漂移也会改变
     VFM 的场量残差或本构参数，因此必须将同步误差作为显式质量指标。
```

生成：

```text
wiki/PA12-DIC-VFM-研究问题与假设.md
wiki/PA12-DIC-VFM-创新候选与证据链.md
```

### 阶段 1C：无试样同步干跑和 2D DIC 可行性

先不做正式材料试验，只验证测量链：

1. 触发事件能否同时写入相机和机器记录；
2. 帧号与机器采样号是否连续；
3. 时间映射和残差能否计算；
4. 平面标定/刚体移动时 DIC 是否出现虚假应变；
5. 2D 假设下的面外运动是否可忽略或可量化。

生成：

```text
实验/PA12-双轴-DIC-VFM/04_帧力位移同步验证.md
实验/PA12-双轴-DIC-VFM/06_MatchID2019前处理标定.md
实验/PA12-双轴-DIC-VFM/同步/events.csv
```

### 阶段 1D：最小预试验

只有 1A–1C 通过后才做低载荷 PA12 预试验。第一轮不追求最大应变，而追求：

- 中心观测区有可用相关点；
- 夹臂/槽端没有提前破坏；
- 力、位移、帧号和事件号能一一追溯；
- 整体响应与 DIC 全场趋势相容；
- 候选 VFM 参数对小幅噪声和 ROI 掩膜不过度敏感。

## 5. 相机参数的当前处理策略

现在只向你索取能够改变实验决策的参数，不要求先提交完整相机采购表：

```text
优先：是否可硬件触发、实际帧率、曝光、视场、像素尺度、时间戳
其次：镜头/工作距离、照明、散斑、标定误差、MatchID 2019 导出字段
最后：品牌、型号、宣传册最高帧率
```

型号最后确认也可以推进 1A 和 1B；但没有帧号、触发/时间戳和标定误差，不能推进 1C 之后的 VFM 正式结论。
