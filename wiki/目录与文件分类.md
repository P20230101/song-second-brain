# 目录与文件分类

本页是 Vault 的文件分流规则。分类依据是文件的职责，而不是文件的来源软件。

## 正式结构

```text
根目录/
├── index.md                         # 公开 Wiki 总入口
├── AGENTS.md                        # 维护规则与 Schema
├── log.md                           # 追加式维护日志
├── README.md                        # GitHub 项目说明
├── wiki/                            # 已整理、可复用的知识页面
│   ├── 研究上下文.md
│   ├── 每日学习闭环-YYYY-MM-DD.md
│   ├── 文献捕获与筑巢.md
│   ├── 科研流水线SOP.md
│   └── 目录与文件分类.md
├── raw/                             # 原始来源，只读，不改名、不改写
│   └── 参考文献/                     # PDF 与 download_manifest.json
├── 实验/                             # 代码、Notebook、数据副本、结果和图表
├── tools/                            # 可复用的本地工具脚本
├── inbox/                            # 尚未升级为正式知识的本地材料
│   ├── 对话/                         # 原始 AI 对话日志（本地私有）
│   ├── 日记/                         # Obsidian 日记与临时记录
│   └── 摘录/                         # 网页或其他来源的未处理摘录
├── docs/superpowers/                 # 项目设计与实施历史记录
└── .obsidian/、.claudian/ 等         # Obsidian/AI 插件运行状态
```

## 分流规则

- 能直接作为证据追溯的原始 PDF、网页导出和下载清单进入 `raw/`；进入后只读。
- 经过核对、可复用的研究结论进入 `wiki/`，并在 `index.md` 登记。
- 当天对话、未确认的推断、空白日记和网页剪藏进入 `inbox/`，不得直接升级为研究事实。
- 实验脚本、Notebook、数据副本和输出进入 `实验/`；实验结果必须记录运行环境和命令。
- 仅为 Obsidian、Claudian、Copilot 或其他本地工具服务的目录不属于知识层；保留其原路径以避免插件失效，并通过 `.gitignore` 排除出公开仓库。
- `docs/superpowers/` 是实施过程的历史记录，不与正式研究结论混合。
