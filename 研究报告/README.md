# 科研报告中心

本目录保存围绕 PA12 双轴拉伸、工业相机 2D DIC 与 VFM 的周期性研究报告。

```text
研究报告/
├── 日报/     # 由 Obsidian 的“打开今日笔记”命令创建
├── 周报/     # 新建文件后插入“科研周报”模板
└── 月报/     # 新建文件后插入“科研月报”模板
```

## 使用方式

1. 在 Obsidian 命令面板运行“打开今日笔记”，自动在 `研究报告/日报/` 建立当天日报并套用“科研日报”。
2. 每周建立 `研究报告/周报/YYYY-Www.md`，运行“插入模板”，选择“科研周报”。
3. 每月建立 `研究报告/月报/YYYY-MM.md`，运行“插入模板”，选择“科研月报”。
4. 每日 21:00 的“第二大脑价值审查、报告与同步”任务会补建当天日报、周日周报和月末月报；它不会覆盖已写入的内容。
5. 日报记录当日证据和问题；周报只汇总已核对项目；月报只汇总形成闭环的资产与下月验证目标。

模板放在 `模板/`，Obsidian 的模板目录和每日笔记目录已完成配置。
