# 2026-09-14 政策与课标候选来源

本页只记录已打开的官方来源及其可用边界。它们用于说明研究背景与规范性要求，不替代教材课时原文，也不构成“十几减9”练习已经有效的实证证据。

## 1. “双减”意见（教育部）

- **来源：**[关于进一步减轻义务教育阶段学生作业负担和校外培训负担的意见](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202107/t20210724_546566.html)
- **类型：**政策文件，2021-07-24 发布。
- **可支持的背景论断：**义务教育作业治理强调控制总量、提高质量、优化作业设计与反馈管理。
- **适用边界：**这是政策要求，不是对本研究课时练习效果的测量；不据此推断学生成绩、负担或兴趣变化。

## 2. 作业设计与分层线索（教育部专题页面）

- **来源：**[作业设计要体现基础性、综合性和实践性](https://www.moe.gov.cn/jyb_xwfb/moe_2082/2021/2021_zl53/tsj/202112/t20211214_587201.html)
- **类型：**政策解读/实践指导。
- **可支持的设计线索：**作业可按基础、综合与实践等功能组织，并通过梯度和反馈服务不同学习需要。
- **适用边界：**页面不是“十几减9”教材原文，也没有提供本研究的学生样本或测量结果；文中设计线索须与课时目标重新对应。

## 3. 作业评价功能（教育部专题页面）

- **来源：**[发挥作业育人功能，提升作业设计质量](https://www.moe.gov.cn/jyb_xwfb/moe_2082/2021/2021_zl53/tsj/202112/t20211210_586280.html)
- **类型：**政策解读/实践指导。
- **可支持的设计线索：**作业可以同时承担知识巩固、反馈与思维发展的功能，评价应与目标和任务对应。
- **适用边界：**不能把规范性表述写成已在本课时实施并验证的结论，也不能替代逐题设计审查。

## 4. 《义务教育数学课程标准（2022年版）》

- **来源：**[义务教育课程方案和课程标准（2022年版）](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582346895190.pdf)
- **类型：**国家课程标准 PDF。
- **本项目已定位内容：**第一学段“数与运算”印刷页 18（PDF 第 25 页）关于探索加减法算理与算法、在情境中体会数和运算意义的条目。官方 PDF 为扫描版，已渲染并 OCR，片段登记为 `SRC-MOE-2022-MATH:page-18`，E-022/E-023 状态为 `verified`。
- **适用边界：**课程标准提供目标与评价方向，不直接提供“十几减9”某一课时的题目，也不提供本项目的学生学习结果。

2. 第三方书目页面给出该 2024 版的 ISBN 候选 `9787107382451`，只能作为线索，尚未与 PDF 版权页或纸本核对，不能写入已核验书目。
3. 已取得教师教学用书扫描版镜像并 OCR 相关页；E-014—E-017 仍为 `needs_review`，不能替代正式教材原页。
4. 题目中的算式、表征和题量在正式教材书目与页码核对前仍是设计变量；下一轮要补“课标要求—教材目标—题目—评价指标”的逐项映射。
