# 可复现实验方案与数据补齐清单

## 1. 研究设计

研究类型为实验—数值结合的测量方法研究。先完成设备和测量链的可行性预试验，再进行正式的双轴拉伸测试和 VFM 识别。正式实验开始前不锁定超出设备资料支持范围的加载速度、最大载荷、相机帧率或试样尺寸。

### 1.1 研究对象

- 材料：PA12；成形方式、牌号、粉末批次、含水状态和后处理必须在实验记录中确认。
- 试样：十字形双轴拉伸试样；中心减薄、狭缝、圆角和臂宽由有限元初筛并结合可加工性确定。
- 方向：若确为 SLS，候选比较为 XY 与 XZ；若实际材料不是 SLS，必须删除“打印取向/层间结合”的推断并重新定义变量。
- 观测：试验机四通道力/位移和工业相机 MatchID 2019 2D-DIC。当前投稿路线固定为 2D；3D 仅作为未来可选扩展，不是本项目当前计算或投稿的前置条件。

### 1.2 加载路径

最低可行路径为：X向单轴、Y向单轴和等双轴拉伸。只有设备能独立控制并记录两个方向的加载量时，才增加非等双轴应力比。每条路径须预先定义控制量、加载速率、终止条件、力/位移符号和是否保持/卸载。

高速加载不由设备宣传的最高速度自动决定。若试验拟采用动态速度，必须额外记录相机曝光、帧率、同步事件和加速度，并在动力学平衡式中核对惯性项。没有这些证据时，正文只写准静态测量链。

## 2. 阶段门控

### Gate 0：设备与安全

取得设备说明书、夹具结构/照片、控制器触发说明和校准记录；确认双轴是否独立闭环、力传感器量程对应单通道还是总通道、有效行程和安全限位。没有确认前，不加工最终试样和不进行高载荷测试。

### Gate 1：无试样同步验证

在不装试样的情况下同时记录触发事件、相机帧号、试验机时间戳、四通道力和位移。形成唯一映射：

```text
frame_id -> t_image -> t_machine -> machine_sample_id 或插值区间
```

输出同步残差、掉帧记录、重复触发记录和时钟漂移。标称频率相同不能替代同步验证。

### Gate 2：2D-DIC 测量质量

完成平面标定、静止图像噪声底、刚体面内移动检验和面外运动风险评估。记录相机型号、镜头、分辨率、视场、像素尺度、曝光、照明、散斑特征尺寸、MatchID 版本、subset、step、形函数、相关准则、应变窗口和滤波设置。

### Gate 3：低风险预试验

使用同一批次或可追溯的 PA12 预试样，检验散斑附着、四臂夹持、通道平衡、中心区场量完整性、臂根/圆角/狭缝端部是否提前局部化，以及 DIC 场与机器位移的量级是否一致。

### Gate 4：正式试验

正式试验按试样随机编号执行；试样是统计独立单位，图像帧不是独立试样。每个试样保存原始图像、原始机器数据、MatchID 工程文件、导出场量、元数据和分析版本。任何删除帧或改变 ROI 都写入运行清单。

### Gate 5：VFM 识别与独立验证

先用 L0 线弹性模型检查单位、坐标、边界力、厚度、虚场和积分实现；只有 L0 通过才考虑有限应变、塑性、黏弹或各向异性模型。拟合集与验证集在分析前预先划分；验证集不重新调参。

## 3. 试样有限元设计

定义几何向量

\[
g=(h_c,N_s,l_s,r_f,s_s,w_a,\ldots),
\]

其中 \(h_c\) 为中心区厚度，\(N_s\) 为每臂狭缝数量，\(l_s\) 为狭缝长度，\(r_f\) 为圆角半径，\(s_s\) 为狭缝间距，\(w_a\) 为臂宽。工作区本地学习基线中的具体数值只能作为候选初值；最终值要同时满足设备行程、夹具宽度、材料厚度和打印/加工分辨率。

对每个几何候选，输出：

1. 中心 gauge region 的主应变均匀性和应力状态；
2. 中心区与臂根、圆角、狭缝端部的最大等效应变/应力比；
3. 在 X/Y/等双轴加载下的变形模式；
4. 结构失效位置是否落在预定义测量区；
5. 网格、材料模型和边界条件的版本。

FE 的作用是筛选和解释试样设计，不代替真实 DIC/力数据。材料模型若来自文献，必须记录出处和参数来源；不得把文献参数称作本项目测量值。

## 4. 同步与坐标映射

若由触发事件获得成对时间点 \((k_i,t_{m,i})\)，可在已验证的采样区间内拟合

\[
t_m(k)=a+bk,
\]

并记录每个图像帧映射到机器时间轴后的残差

\[
e_i=t_{m,i}^{\mathrm{mapped}}-t_{m,i}^{\mathrm{observed}}.
\]

若存在非线性时钟漂移，不能继续使用单一线性映射；需依据实际触发记录重新定义映射。所有插值必须保留原始时间戳和插值区间，不能人工平移曲线后删除残差记录。

## 5. DIC 数据接口

每个有效帧至少保存：

```text
frame_id, t_image, x, y, u, v,
exx, eyy, exy（若由软件导出）, correlation_quality,
valid_mask, roi_id, dic_run_id
```

同时保存：

```text
camera_model, lens, image_size, fps, exposure,
calibration_method, scale, subset_size, step_size,
shape_function, interpolation, strain_window, filter,
speckle_description, software_version
```

`x,y,u,v` 的单位、坐标原点、轴方向和正负号必须与机器力/位移和 VFM 求解器一致。有效点掩膜和边缘缺失不能在分析中临时改变而不留版本。

## 6. VFM 接口与识别

准静态平面应力假设下，对每个时刻和虚场 \(\mathbf u^*\) 计算

\[
r_k(\boldsymbol\theta)=
\int_{V}\boldsymbol\sigma(\boldsymbol\varepsilon(\mathbf x,t_k);\boldsymbol\theta):
\boldsymbol\varepsilon^*(\mathbf x)\,\mathrm dV
-\int_{\partial V}\bar{\mathbf t}\cdot\mathbf u^*\,\mathrm dA.
\]

其中 \(\boldsymbol\theta\) 是待识别参数，边界项由四通道合力和受力区域定义得到。若边界力只有合力而没有分布，必须写出由合力换算边界牵引的假设、受力宽度和厚度，不能把合力自动当作边界每一点的局部应力。

L0 识别目标可写为加权最小二乘：

\[
\hat{\boldsymbol\theta}=
\arg\min_{\boldsymbol\theta}\sum_{k\in\mathcal F}\sum_{q\in\mathcal Q}
w_{kq}r_{kq}^{2}(\boldsymbol\theta),
\]

其中 \(\mathcal F\) 是拟合帧集合，\(\mathcal Q\) 是虚场集合，权重来源需记录。拟合后输出参数、残差、条件数或灵敏度、初值/边界、优化器和运行版本。

## 7. 敏感性与验证

至少建立以下分析版本：

- 同步基线、提前/延后映射的受控扰动；
- 完整 ROI、边缘掩膜 ROI 和不同但预先定义的中心 ROI；
- 不同 subset/step/应变窗口的合理设置；
- 只用整体力—位移的基线；
- DIC 全场 VFM；
- 一条未参与拟合的加载路径或一组独立试样。

输出指标包括整体力/位移预测误差、场量残差空间分布、虚功残差、参数变化区间和试样间重复性。不能把不同图像帧当作不同试样，不能把验证集重新用于调参。
