# 2026-09-14 代码纵切片

## 已完成

- `contracts.py`：项目、来源、段落、证据、任务和运行状态契约；运行状态保存显式 `stage_evidence`。
- `retrieval/`：OpenAlex、Crossref、Semantic Scholar、OpenAI 网页搜索适配器；`httpx` 全文获取；BeautifulSoup/trafilatura HTML 解析；PyMuPDF PDF 解析。
- `storage/sqlite.py`：项目、来源、段落、证据、运行、任务和产物表。
- `harness/`：Luna/Sol 路由、xhigh/high 推理档位、来源风险升级、任务门禁、Token 预算和完成度检测器。
- `harness/retry.py`：对明确的瞬时外部错误执行有上限的指数退避，最终错误仍会保留。
- `agents/registry.py`：总编辑计划器；检测报告驱动研读、证据、大纲、四个章节写作、审稿和图件任务。
- `graph/workflow.py`：需求登记 → 文献搜索 → 全文获取 → 定位解析的 LangGraph 纵切片。
- `api/app.py`：项目/运行 CRUD、`GET /runs/{run_id}/audit`。
- `cli.py`：`python -m paper_cluster research` 和 `python -m paper_cluster audit`。
- `documents/export.py`：将审核后的 Markdown 导出为 DOCX 与带中文字体的 PDF。
- `storage/vector.py`：可选 Chroma 向量索引，保留 passage 定位元数据，embedding 由调用方提供。
- `.env.example`：OpenAI、OpenAlex/Crossref 邮箱和 Semantic Scholar key 的配置入口。

## 当前门禁

纵切片在“文献研读”阶段停下。下一步必须由 Literature Research Agent 研读已解析原文，再由 Evidence Agent 逐条登记带页码或章节定位的证据；完成检测器会把该阶段报告为下一任务。没有真实学生数据时，Result Agent 只能生成分析计划和待采集项。
