# PA12 双轴-DIC-VFM｜最小预试验矩阵

## 使用边界

这是一份测量链预检矩阵，不是正式论文试验矩阵。它不预设相机品牌、最终试样尺寸、正式载荷、加载速度或本构模型；这些值必须来自设备资料、用户现场记录和文献核对。

目标只有三个：

1. 证明图像帧、力/位移采样和事件号可以追溯到同一时间轴；
2. 证明 MatchID 2019 在当前视场、散斑和 2D 假设下能输出可用场量；
3. 在低风险条件下比较整体力—位移与 DIC 全场输入，为候选 B 的正式设计提供基线。

## 固定配置与待定变量

### 整个预试验期间固定

- 同一套数据目录、文件命名和 `events.csv` 字段；
- 同一坐标系、单位和符号约定；
- 同一 MatchID 2019 工程文件版本；
- 同一照明、相机位置和视场；
- 所有原始图像、机器原始数据和事件日志只读保存；
- 每个改变都写入 `operator_note`，不在事后凭记忆补写。

### 只有确认后才填写

```text
设备型号和每通道额定力
有效行程和安全停止窗口
相机实际帧率、曝光、时间戳/触发接口
MatchID 2019 的工程文件和导出字段
PA12 成形方式、厚度、试样外形和夹具适配
允许的低载荷范围和重复次数
```

## 预试验矩阵

每一行只改变一个主要因素；如果设备条件导致必须同时改变多个因素，必须把它记为新配置并停止与原行直接比较。

| Run ID | 目的 | 主要因素 | 本行设置 | 固定项 | 记录 | 预期结果 | 通过后进入 |
|---|---|---|---|---|---|---|---|
| P0 | 共同事件链干跑 | 是否触发/事件写入 | 无试样；执行 `ARM → START → STOP` 及一次可识别事件 | 相机位置、机器采样配置 | `event_id、trigger_id、frame_id、machine_sample_id、两个时间戳` | 两套系统均有连续事件；映射规则可写出 | P1 |
| P1 | 平面/静态 DIC 基线 | 无载图像重复 | 固定相机和标定板/平面目标，重复采集 | 光学设置、MatchID 工程文件 | 像素尺度、标定误差、静态位移/应变噪声 | 静态场量处于预先定义的噪声范围内，无系统漂移 | P2 |
| P2 | 已知位移和前处理折中 | `subset、step、应变窗口、滤波` 中的一项 | 在同一图像序列上逐项扫描，一次只改一个参数 | 图像序列、标定、坐标系 | 相关质量、位移误差、应变噪声、空间分辨率 | 得到“精度—分辨率”曲线；不只选择最平滑结果 | P3 |
| P3 | 低载荷整体基线 | 加载状态 | 1 个经确认几何的 PA12 流程试样；只采用安全低载荷路径 | 试样、相机、同步、MatchID 设置 | 两方向力/位移、图像、异常事件、裂纹/脱粘位置 | 力—位移可追溯；中心区有可用 DIC 场；无夹臂先失效 | P4 |
| P4 | 主线 B 的最小对照 | 数据输入 | 对同一试验分别做“整体力—位移基线”和“整体 + DIC 全场”处理 | 同一试样、同一时间轴、同一边界条件 | 两套识别输入、残差、参数不确定度、场量质量 | 能定量比较全场信息是否改变识别稳定性/验证误差 | 正式试验设计 |
| P5 | 质量闸门 A | 时间对齐 | 在 P3/P4 的派生数据中只改变固定偏移或漂移模型 | 原始数据和 DIC 结果 | 同步残差、VFM 残差、参数变化 | 可见“整体曲线正常但 VFM 受时间错位影响”的边界，或证明影响很小 | A/B 方向决策 |
| P6 | 最小重复性检查 | 独立试样 | 按预先确定的重复数重复 P3；不把图像帧当独立样本 | 已通过的 P0–P5 设置 | 试样编号、批次、几何、结果和异常 | 结果差异可解释；若不可解释，返回几何/同步/散斑检查 | 正式试验矩阵 |

## 各 Run 的停止条件

遇到下列任一情况，停止进入下一行，并在事件表记录原因：

- 触发号、帧号或机器采样号无法追溯；
- 图像帧出现未解释的丢帧或重复帧；
- 静态/刚体测试出现未解释的系统应变；
- 2D DIC 出现明显面外运动而没有量化方法；
- 力/位移单位、符号或通道含义不一致；
- 试样在夹臂、槽端或非观测区先发生无法解释的破坏；
- 原始图像、机器数据或 MatchID 导出文件缺失；
- 载荷或位移超出设备资料确认的安全窗口。

停止不是失败。停止记录本身可以成为几何、同步或测量边界的证据；但在问题未解释前，不能把该行数据用于 VFM 正式结论。

## 预先定义的分析输出

### P0/P1：测量链

```text
实验/PA12-双轴-DIC-VFM/同步/events.csv
实验/PA12-双轴-DIC-VFM/04_帧力位移同步验证.md
```

至少输出：事件时间线、帧—采样映射、丢帧列表、同步残差、静态位移/应变噪声、标定误差。

### P2：参数选择

```text
subset/step/应变窗口/滤波的参数表
相关质量—位移误差—应变噪声—空间分辨率对照图
推荐起始配置及其适用范围
```

推荐配置只能作为本机预试验结果，不能把其他论文的数值改写成本项目最佳值。

### P3/P4：主线 B

```text
实验/PA12-双轴-DIC-VFM/results/整体力-位移基线.md
实验/PA12-双轴-DIC-VFM/results/DIC全场质量.md
实验/PA12-双轴-DIC-VFM/results/VFM识别与验证.md
实验/PA12-双轴-DIC-VFM/results/交叉验证.md
```

比较指标至少包括：整体曲线误差、场量残差、候选参数估计、重复性/不确定度和独立路径验证误差。

### P5：质量闸门 A

```text
时间偏移/漂移敏感性表
VFM 参数变化曲线
同步质量判据及适用范围
```

P5 使用的是派生数据扰动，不替代真实硬件触发验证；它的作用是量化风险，而不是伪造同步精度。

## 资源估计

| 资源 | P0–P2 | P3–P4 | P5–P6 |
|---|---|---|---|
| 试样 | 无 | 先按 1 件流程样；不可用于最终统计 | 由重复性设计确定 |
| 机时 | 不占正式加载机时或只占干跑时间 | 低载荷安全窗口内 | 处理已有数据为主 |
| 图像存储 | 原始短序列 + 导出字段 | 原始图像序列必须保留 | 派生表格和图形 |
| 计算 | MatchID 2019 前处理参数扫描 | DIC + 整体基线 + VFM 试跑 | 时间轴扰动和稳定性比较 |

不在设备、图像和导出格式确认前填写具体分钟数、帧率或载荷数值；这些值应从现场记录得到，而不是从宣传页猜测。

## 通过判据

预试验只有同时满足以下条件，才允许设计正式试验：

1. `events.csv` 的事件、帧号和机器采样号可回溯；
2. 同步残差的计算方法、参考时钟和容许范围已写明；
3. MatchID 2019 的坐标、单位、ROI、质量字段和导出格式固定；
4. 平面/静态或刚体测试没有未解释的系统应变；
5. 2D 假设的适用范围已通过观察或独立量化说明；
6. 低载荷流程样没有在夹臂/槽端先失效，或者失败原因已归因并反馈到几何设计；
7. 整体力—位移、DIC 场量和 VFM 试跑能在同一时间轴上对照；
8. P4/P5 的结果足以决定是否继续主线 B、单独研究 A，或返回调整测量链。

## 需要用户补齐的资料

按优先级提供，不需要一次性准备完整设备档案：

1. 试验机控制器的采样和触发说明、两方向通道名称及单位；
2. 相机是否可接受 TTL/硬件触发，是否导出实际时间戳；
3. 一段真实的力/位移导出样例和一组 MatchID 2019 导出样例；
4. PA12 试样的成形类别、厚度、可用外形范围和夹具限制；
5. 低载荷试验的安全窗口和允许重复数。

相机品牌/型号可以最后补齐；只要 P0 所需的事件、时间戳或可观测对齐信号可获得，就能先推进测量链验证。
