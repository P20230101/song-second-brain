# VFM PLAN｜Virtual Experiment、数据契约与识别闭环

## 1. VFM 输入契约

每个可识别帧或窗口必须同时具备：

- 坐标 `x,y` 与单位；
- 位移 `u,v` 或应变 `exx,eyy,gxy`，以及 DIC 质量指标和有效掩膜；
- 厚度 `t`、真实 ROI、应变窗口/平滑方式和边缘剔除规则；
- `Fx,Fy`、符号约定、力单位、边界作用区或可推导的边界合力；
- `t_image`、`t_force`、同步方法和同步残差；
- 试样、方向、路径、速率、重复编号和原始文件来源。

契约任一项缺失时，该窗口只能用于审计或 synthetic 试验，不得进入真实参数识别。

## 2. Virtual Experiment 顺序

```text
θtrue + 几何 + 边界路径
        ↓
独立 Abaqus 真值模型（场量与边界力同时输出）
        ↓
统一坐标、单位、ROI、时间和采样
        ↓
无噪声全场 → VFM → θidentified
        ↓
θidentified 与 θtrue 比较
        ↓
再加入 DIC 空间噪声、力噪声、边缘缺失、时移和模型形式误差
        ↓
最后才进入真实 PA12 数据
```

无噪声不能回收时必须停止，不允许直接调真实数据参数。

## 3. 识别对象与对照

至少建立三种信息集：

1. `curve-only`：整体 Fx/Fy 或力—位移曲线；
2. `uniaxial-field`：单轴全场 + 边界力；
3. `uniaxial + biaxial-field`：单轴与双轴全场 + 边界力联合。

所有模型用同一参数化、同一尺度化、同一训练/留出规则比较。VFM 的核心残差是虚功平衡残差；内部虚功、外部虚功、边界区域和每帧权重必须分别记录，不能只保存一个最终优化目标。

## 4. 模型与数值顺序

- 先实现并核对 M0；
- M0 通过独立 Virtual Experiment 后，再实现 M1/M2；
- M3–M7 只有在 [CONSTITUTIVE_MODELS.md](CONSTITUTIVE_MODELS.md) 的证据条件满足时开放；
- 优化器、初值、参数尺度和收敛阈值固定记录；
- 目标函数低不等于参数正确，优化器收敛不等于识别成功。

## 5. 当前 L0 基线的正确定位

项目已有平面应力 L0 合成基线，能对由同一矩阵生成的 RHS 做代数回收。这是有用的代码/线性代数基准，但还不能代替：

- Abaqus 真实场量进入内部虚功的闭环；
- 边界力与场量来自同一物理加载状态；
- 真实 PA12 的本构积分、单位、几何和同步验证。

计算力学复核已将当前 Gate 3/4 判为 `FAIL/BLOCKED`：合成场存在位移—应变不相容，外功由真参数和同一矩阵循环构造；Abaqus 基准只有均匀等双轴状态、未导出边界反力，也没有把 FE 场量接入 VFM 内外功。因此现有结果只能保留为代数/程序原型，不能称为物理 Virtual Experiment 或 PA12 真参数回收。

重开 Gate 3 的最低条件：虚场由 admissible 位移场导出应变；真值场由独立 FE 计算产生；边界反力由 FE 输出；加载状态至少包含能够激活目标参数的异质应变；内部虚功和外部虚功分别可追溯。重开 Gate 4 后才允许做噪声和真实实验。

## 6. 真实数据准入与退出

真实数据进入 VFM 前需要逐项记录通过/失败。若解析后发现只有剖面 CSV、没有二维场，或无法建立力—图像时间关系，退出真实 VFM 识别，转为：

- MatchID 数据可追溯性与字段解析；
- 同步/ROI/边缘缺失对识别的虚拟误差传播；
- 以 synthetic data 验证方法边界。

这是有效的研究降级路线，不把缺失证据藏在优化结果里。

## 7. 当前首轮代码的最小数据包

已从 `yuan/data` 全量找到并审计 14 个试验目录、6,327 个 `.dat`（XY 5,295、XZ 1,032）。首轮代码不读取原始图像，而读取由审计脚本产生的标准化中间表：

```text
trial_id, frame_id, x_px, y_px, u_px, v_px,
u_mm, v_mm, R, Sigma, valid_mask,
Fx_N, Fy_N, t_image_s_est, sync_status
```

其中 `x/y/u/v` 的字段语义和单位必须先由 MatchID 2019 导出说明确认；当前 `.dat` 审计只把字段 7/8 保留为“位移候选”，字段 9–12 保留为“应变候选”，不把候选名改成已证实语义。厚度先按用户确认的 `1.0 mm` 写入配置；几何和边界牵引仍使用试样真实尺寸与夹具记录。

首轮只输出三类文件：

1. `all_matchid_dat_summary.csv`：每个试验一行，判断是否存在连续全场入口；
2. `all_matchid_dat_frame_audit.csv`：每个 DAT 帧一行，记录点数、R/Sigma 和解析状态；
3. `all_matchid_dat_force_candidates.csv`：已有 XY 照片—力表按试验编号/帧号合并，缺 DAT 的照片明确标记，不填猜测场。

这三类文件已在本地生成，路径见 [ALL_TRIALS_AUDIT](ALL_TRIALS_AUDIT.md)。它们是进入 VFM 前的审计层，不是最终本构参数结果。下一轮代码只允许消费 `解析状态=可解析`、点数/质量掩膜通过且同步情景已明确的帧段。
